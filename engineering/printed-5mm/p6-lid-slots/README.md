# P6: printed-5mm フタ天板の長穴

`P6-PRINTED-5MM-LID-SLOTS`。7U40家庭印刷の大きいフタ天板2枚だけを
P5から交換する増分改訂です。**同じSTLを2枚印刷します。**

`out/stl/lid-top-1.stl` を2枚印刷し、組み立てるときに片方を板の面内で
180度回して配置します。裏返しや鏡像化は不要です。
`lid-top-1` と `lid-top-2` は組立位置を区別するIDで、形状は180度回転で
一致します。既存の2ファイルは組立座標・対応関係のために保持しています。

- 天板は1形状を2枚。各225.8 × 165.05 × 5 mm。
- 各板4か所、計8か所のM5用丸穴を10.5 × 5.5 mmの長穴に変更。
- 長軸は対応する外周辺に直角。公称の中心から前後2.5 mmずつ調整可能。
- 穴端から板外周までの最小距離は5.45 mm。
- 本体6枚、L字のフタ縁4枚、任意のパッド／座金3型はP5のまま再使用。
- 外形、5 mm厚、0.3 mm中央隙間、組立座標、締結部の中心位置は保持。
- STLはmmの印刷姿勢。平面を下にしたZ=0配置で、追加回転や拡大縮小は不要。
- STEPは組立座標。印刷姿勢への移動量は `parameters.json` を参照。

## Bambu Studioプロジェクト

`out/projects/` の2個の3MFは対応するP5の保存済みプロジェクトから
メッシュだけを差し替えています。H2D・0.6 mm・PLA、ブリム0 mm、
フィラメント割当、位置、ID・UUID、その他の印刷設定を保持。
プロジェクト名と説明はP6へ更新しています。

印刷には `out/projects/p6-lid-top-1-h2d-pla06.3mf` を使い、同じモデルを
2枚印刷します。1ファイル・1プレートに天板1枚です。もう一方の3MFは
180度向きを変えた同形部品です。

未スライスでG-codeなし。構造と配置の検査は実施、
Bambu Studioでのロード／スライスおよび現物嵌合確認は未実施です。
家庭印刷ケースの設計材料はASA想定ですが、ユーザーの保存済み3MFのPLA設定を
この改訂で変更していません。

## 再生成

Python 3.13.5 / CadQuery 2.8.0。P5のSTEP・3MF入力は `reference/` に
固定し、`parameters.json` のSHA-256で検証します。P5の本体・縁部品を
再生成または変更するスクリプトではありません。

```sh
uv sync --locked
uv run python build.py
uv run python regenerate.py
```

`build.py --out /absolute/empty/output` で別ディレクトリにも出力できます。
出力は2個のSTL、2個のSTEP、2個の3MF、および `verification.json`。
`regenerate.py` は一時ディレクトリで作り直し、保存済み7出力のバイト一致と、
天板2枚が180度回転で同形になることをSTEPの差分で検査します。

検査は閉じた単一メッシュ、巻き方向、寸法、P5への追加材料なし、
除去体積550 mm³/枚、全長穴の中央と両端でのM5軸の通過、
最小外周残し、STEP読み戻し、3MF/STL一致、印刷設定バイト一致です。
同形性は組立座標の `lid-top-1` をZ軸まわりに180度回したSTEPと
`lid-top-2` の双方の差分体積が0 mm³であることを確認しています。
これらは現物の嵌合・締付け・強度・反りを確認するものではなく、
`production_approved` は `false` を保持します。
