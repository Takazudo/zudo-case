# P4・H2D用3MFを作成済み（未スライス）

`P4-H2D-3MF-PLA06-R1`。P4 Uniformケースの形状を変更せず、保存済みH2D・0.6mmノズル・PLAテンプレートから作成しました。ユーザーが詳細を調整するため、積層、壁数、インフィル、温度、サポート、ブリムなどの設定は変更していません。印刷開始・プリンターへの送信は行っていません。

## 使うファイル

`projects/` に15種類の3MFがあります。1ファイル＝1プレート＝1部品です。

- 構造12部品: 床2枚、壁4枚、蓋の縁4枚、屋根2枚。各1個。
- 任意3種類: 横パッド、縦パッド、丸座金。各プロジェクトには1個だけ入っています。必要数はStudioで複製してください。元P4台帳の数量はパッド各48・丸座金28で、`PROJECTS.json` に併記しています。
- レール・PCB・金属金具は含みません。

通常13種類は元テンプレートの `Metadata/project_settings.config` をバイト単位で保持しています。黒のフィラメントスロット1（Bambu PLA Basic）を使用します。元の工程は0.24mm Balanced Strength、壁2周、インフィル15%、サポートOFFです。これはその設定を推奨・検証した意味ではありません。特に段付き蓋の縁のサポートなどはStudioで調整してください。元のP4設計の材料想定はASAですが、今回の3MFはユーザー指定のPLAです。

## 長壁2枚は右ノズルで配置

`p4-wall-left-h2d-right-pla06.3mf` と `p4-wall-right-h2d-right-pla06.3mf` は、手動Right割り当てです。フィラメントスロット番号と物理ノズル番号を混同しません。Bambu Studio 2.8.2.61の公式実装でManualのRight＝2を確認し、グローバルとプレートのManual設定、フィラメントmapを再読込で確認しています。

341mmの長壁は単ノズルの325mm幅を水平では超えるため、今回の配置は元P4の45度平置きを使います。45度以外を禁止するものではなく、形状の縮小・分割は行っていません。

- 実STLの投影外形: 約303.912×303.912mm。
- 右ノズル領域: X25–350、Y0–320mm。
- 配置: X約35.544–339.456、Y5–308.912mm、Z0–5mm。
- 保存テンプレートの除外領域と、部品の範囲内・Z0接地を検査。

[長壁の配置図](verification/long-wall-layout.svg)を参照。両ノズル合計350mmを単ノズル幅と扱ってはいません。ブリム・サポート・パージタワー・実ツールパスの余白は未スライスのため未確認です。

## 検証済みの範囲

全15ファイルのZIP/XML、部品ID、メッシュ閉鎖・向き・正体積、プレート内配置、Z0接地、設定保持を確認しました。公式Bambu Studio 2.8.2.61のCLIで15ファイルすべてを読み込み・再保存し、形状の外形（許容0.002mm）・三角形数・設定の保持を確認しています。G-codeは含みません。

この環境ではStudioのOpenGLサムネイル初期化ができませんでした。Studio再保存時の壊れたサムネイル参照は検証用コピーだけから除去して検査し、モデルXMLと印刷設定を変更していないことを確認しました。配布する元の生成3MFにはサムネイル参照自体を入れていません。GUI表示・実スライス・支持・反り・強度・嵌合を検証したとは扱いません。

`verification/*.json` に各部品の検査結果、`PROJECTS.json` にファイル・hash・数量・配置、`SOURCE-RECEIPT.json` に元データと実装根拠を記録しています。

## 編集・再生成

3MFをStudioで開いて詳細設定を変更できます。`manifests/` に配置、`input-stl/` に無変更のP4 STLを同梱しています。CADを変更する場合は `cad-source/printed-5mm-p4-uniform-vents-source.zip` が元の維持ソースです。

```sh
python3 build.py --out /tmp/p4-h2d-new
# 対応するStudioがある場合は読み込み・再保存も実行:
python3 build.py --out /tmp/p4-h2d-checked --studio /path/to/bambu-studio
```

出力先は空のディレクトリ。Python3.10以上、標準ライブラリのみ。ヘッドレスLinuxでStudioを使う場合は表示環境が必要です。ローカルの重い検証は共有heavy-guardを通してください。

同梱 `tools/bambu_3mf.py` は、ccref経由のbambu-3mfをこの作業用にコピーしたものです。元スキルは変更せず、OPC名前空間のStudio互換表記と、確認済みRight専用領域の検査を追加しました。
