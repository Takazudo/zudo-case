# エンジニアリング資産の扱い

このフォルダーは系列ごとのCADソース・生成物・検証記録を持ちます。系列は互いに独立しており、ある系列の作業で他の系列のファイル・数量・注文記録を変えません。文書側の入口は`src/content/docs/`の各セクションです。

## 金属ケース（3U60・7U40・7U60）

- `r6-body/`：提供されたR6 ZIPの全内容を保持した本体CADの参照セット。丸穴、仮穴中心、未確定嵌合に注意。3U60・7U60の基準で、R9/R10の出発点。
- `r8-preview/`：提供されたR8 ZIPの全内容。採用した載せ蓋＋バンドの表示専用モデル。
- `r9-prototype-01/`・`r9-fitfix-01/`・`r9-lid-m5-01/`・`r9-anodizing-01/`：7U40の旧・未承認候補R9系。履歴として保存し、`r9-prototype-01/`のPython環境はR10の生成にも使う。
- `r10-fullset-01/`：7U40の現行一式準備候補R10-FULLSET-01（アルミ6枚・PA12 20個・家庭ASA 72個）。製造承認ではない。
- `order-map/`：注文用の対応表とメッシュ検査。
- 旧R7蓋と回転/スライド比較のソースZIPは `../public/downloads/archive/` に保管。

## 家庭印刷ケース（7U40・5mm）

- `printed-5mm/`：P3（通気孔なし）、P4（Uniform四壁通気孔）、P5（J3差し込み接合、現行）と各H2D 3MF。作業ルールは`printed-5mm/AGENTS.md`。

## 2WAY 実験設計

- `two-way/`：F5（不変の原資料）とTW-01（作業版）。作業ルールは`two-way/AGENTS.md`。製作CADではない。

## 共通部品

- `home-print-spacer-01/`：家庭印刷の8mmスペーサー。外径10mm・穴径5.5mmはR6由来の仮寸法。

## 承認

- `release/`：空。製作承認済みファイルだけを将来配置する。

元ファイルのREADMEs・検証ログは当時の記録です。文書整理時にCAD検証や荷重試験を再実行したものではありません。
同梱コードの元の出力パスや依存パッケージはローカルへ合わせて確認してください。過去の生成コードを一括実行して現在の設計を上書きしないでください。
