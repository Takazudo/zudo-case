# 家庭用3Dプリンター向け・内側8mmスペーサー

fixer外面とケース側板内面の間に入れる中空円筒。外側の1mm座金とは別部品です。

- 印刷ファイル：`frame-spacer-h8-od10-id5p5-mm.stl`（1個、単位mm）
- 高さ **8mm**、外径 **10mm**、M5用貫通穴 **5.5mm**。
- 3U60：4個。7U40 / 7U60：各10個。スライサーで必要数を複製。
- 高さ8mmは採用済み。内外径はR6の仮寸法を引き継いだ試作値で、現物測定値ではありません。

## 印刷と現物確認

平らな環状面をベッドに置き、穴を垂直にして100%倍率で印刷します。サポートは不要。まず1個を印刷し、実M5ねじが通ること、高さが8mmであること、fixerと側板の間で金具・ねじ頭と干渉しないことを確認してください。穴が縮む場合はスライサーの穴補正か`spacer.scad`の`bore_diameter`を調整します。高さまで変わる全体拡大は避けます。

中実設定（100% infill）を出発点として、スライス後の壁・空洞を確認します。材料・積層条件・締付トルクは未検証。締付後の潰れや時間経過後の緩みを現物で確認してください。家庭印刷する選択はユーザー指定ですが、物理的な嵌合・締付強度・耐熱・運搬試験の合格を意味しません。`engineering/release/`の承認済み製作データには含めません。

## 再生成

Python標準ライブラリだけで生成・検査できます。

```sh
python3 engineering/home-print-spacer-01/build.py
```

`build.py`のHEIGHT / OD / IDを変更すると寸法を変更できます（検査の期待値も合わせて更新）。OpenSCAD用の編集可能な同寸法ソースは`spacer.scad`です。SCADを変更した場合はOpenSCADからSTLを書き出してください。Python生成器とSCADは独立しており、自動同期しません。

`manifest.json`にR6入力とSTL出力のSHA-256、寸法、個数、メッシュ検査結果を記録します。検査は閉じたメッシュ、面の向き、貫通穴の位相、実出力の外形・穴径・体積を確認します。STL自体には単位情報がないため、取り込み時にmmを指定します。
