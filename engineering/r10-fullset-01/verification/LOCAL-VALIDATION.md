# R10-FULLSET-01 検証記録

2026-10-26、ローカルLinux/WSL。起点main `6a99404a4e4220bb18b88d7d0f063571d1dad7b9`。詳細環境はenvironment.json。CadQuery 2.7.0は既存R9のuv.lockを使用し、2.8へ更新していない。

## 入力・保全

- 引継ぎZIPのCRCと48メンバーのSHA-256を照合（intake.json）。R2の過去検査を今回の検査として数えない。
- R6の元204mmレール・PCB輪郭・非対称レール穴座標を読み出して使用。全本体穴中心を元データと照合（out/source-datums.json）。
- 旧ソース/注文データ467ファイルのバイト保全を回帰検査。2WAY・他サイズの形状は変更していない。
- R9-PROTOTYPEのoutputs-manifest.jsonだけは、所有スクリプト `python -m r9.package` によってcurrent-spec.jsonとuser-decisions.mdの参照ハッシュを更新。その台帳はsync-r9-ledgerで更新。旧物理形状/注文ZIPの変更ではない。

## 公称CAD・書出し

`pnpm build:fullset`。6アルミ、20 PA12、5家庭用座金形状を生成。全31単体STEPを再読込して単一ソリッド・有効形状・体積/寸法一致、全31 STLで閉じた面・辺の向き・正体積・CADとの差を検査。6 DXFは閉じたワイヤーからt1.5実体を再構成し、STEPとの差を照合する。

- 機能穴54（36長穴＋10レール穴＋8蓋穴）、別に吊り穴6。36長穴の最小外縁残り幅4.75mm。
- 静止する板/ガード/ブラケット/座金/元PCB等の全ペア実体交差なし。ねじとねじ山の意図した重なりを単なる干渉に数えず、軸/頭/ナットを相手の実体および元レールの保守的外接包絡へ検査する。
- 両中央の上耳/下耳は接続した各1ソリッドで正の重複体積なし。元R2で見つかった斜面の法線方向t0.969と線接触を、局所t2 web・0.1mm逃げで修正。耳と長い帯はt1を保持。
- 上ガード外壁/内壁/屋根の断面サンプルは各1.0mm。直接座面Z92、蓋天板下面Z122、板227.4×332×1.5。公称ノブ域に4mmの高さ余裕（パネル2＋ノブ25の仮定）。
- 各M5ポケットの有効5.5・屋根1.5・周囲最小1.6、8軸整合、頭と工具の包絡、ナット回り止め・挿入、M5×10/座金なしの積層を検査。蓋の上昇は指定した11高さでのサンプル検査で、連続掃引の証明ではない。
- 本体のD10×長さ20mm工具包絡では、壁側→底板→元レールユニットの順でアクセスする。逆順では底ねじ/元フレームが工具を塞ぐ位置をjoint-checks.jsonへ記録。現物工具の形状保証ではない。
- 3mm仮脚に対する底ネジの圧縮前余裕0.6mm。各吊り穴の残り幅と仮治具棒アクセスを記録。業者承認を意味しない。
- 小さい押さえの輪郭/長穴被覆/耳上受け面積は0.25mm刻みで検査。±2.5mm全域を使用可とはしない。底面座金は元の中心穴のままだとガードに当たるため、同じ20×12外形を穴より内側へ3mm偏心。

## 数量・包装・家庭印刷

`pnpm test:fullset` は欠落、重複部品/数量、別profile、古い寸法、ASAやN1/C2等の混入、移動範囲の不成立、過去バイト保持を検査する。各ZIPは同じ選定manifestを含み、材質別quantity-finish.csvがその業者の対象だけを列挙する。

ASAは縦16・下辺10・内側36・底面10＝72。円形20は底金具裏10＋元レール外10の再使用で、新規印刷数量0。交換用STLは別に付属する。選定蓋は座金なし。BOMは実ねじ・ナット・18金具・元レール/PCB/スペーサー・脚4・バンド2も区別する。

`pnpm build:home-washers --washer-parameters /tmp/r10-custom-washers.json --out /tmp/r10-custom-washer-output` で下辺の偏心1.25/穴半径補正0.05を別出力し、供給ZIPが変わらないことを確認（washer-only.json）。これは独立再生成の検査で、物理的な印刷試験ではない。
