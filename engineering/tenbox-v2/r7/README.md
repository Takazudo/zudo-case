# 10BOX-v2 R7 — 金具間隔・内側ナット・側板締結の確認候補

2026-11-23のR6プレビューへの追加フィードバックを反映する改訂です。対象は独立した10BOX-v2系列だけです。**R7の設計確認待ち**で、採用済みR5とR6の保存ソース・出力は保持します。追跡: [#143](https://github.com/Takazudo/zudo-case/issues/143)、確認PR: [#144](https://github.com/Takazudo/zudo-case/pull/144)。製造承認は`false`です。

## 今回の修正

- 側面のL字金具と新しい底板受けの両脇を**各3mm**空けます。既存の前後板の受けと金具の間隔（公称3mm、保存形状で約3.0069mm）に合わせた値です。R6の0.5mmから拡大します。
- **本体・蓋のL字金具のナットはすべてケース内側**です。底面・壁面・天板の外側にはねじ頭と座金を置きます。独立したレールフレームとケース側板の締結だけは、従来の外側ナットを保持します。
- 新設した側板の穴にも、ねじ・外側座金・内側ナットを含む締結一式を追加します。本体18個・蓋8個の金具の両脚を表示し、穴だけで締結が省略された状態を解消します。
- 中央のnuts型ダブルレール、対応する外周single v3、アルミフレーム／パダーの元形状、各列を内側へ2.73407mm移した位置はR6から引き継ぎます。

R6の「底面ナットを外側にする」という提案は、今回の明示的なユーザー指定によって置き換えられています。R6ファイルは履歴として不変のまま残します。

## 金具とねじの納まり

現在の7U参照は、M5通常ナット高さ4mmと、狭い箇所用の薄ナット高さ2.7mmを区別しています。これらは形状確認用の公称値で、購入済み金具を測った値ではありません。レール固定部の外側座金＋ナット計6mmという確認値を、L字金具すべての内側積層へ流用しません。

R7では本体底面18か所・狭い側板8か所・蓋天板8か所、計34か所に**高さ2.7mmのM5薄ナット**を使います。ナットは金属の金具へ直接当たり、ナットの下へ追加座金を積みません。樹脂壁と金具の間の保護座金、外側の荷重分散座金は保持します。残る前後板・蓋壁面の18か所は通常の高さ4mmナットです。薄ナットは、金具の直角部分で相手側のナットとねじ先端が当たることも避けます。ねじは低頭1.4mm・頭径12mmの公称参照形状で、ねじ山は省略しています。

| 箇所 | R7の納まり |
| --- | --- |
| 側面金具と受けの横隙間 | 両脇に3mm |
| 共通底板の金具座 | R6と同じ深さ1.5mm、残る底厚3.5mm |
| レール面 | Z75.5mm。R5から3.5mm、R6から1.5mm上げる |
| 浅い側の底面締結 | M5×10、内側薄ナットh2.7。ねじ先端の突き出し0.8mm |
| 側板の金具締結 | M5×12、内側薄ナットh2.7。ねじ先端の突き出し0.3mm |
| レールフレーム固定 | M5×25参照、頭はパダーの下。外側座金はOD10 / ID5 / t1mmへ変更し、座金＋ナット計6mmを保持 |
| ケース外形・蓋・通気 | 外形と既存の蓋、側面8mmの間隔、各側16本の通気孔を保持 |

レールを上げた状態では、R6の外径15mmのレール固定座金が載せ蓋の外面に約17.38mm²ずつ接します。この接触を避けるため、レール固定の8枚だけを**外径10mm・内径5mm・厚さ1mm**の公称座金へ変更します。座金と蓋の公称隙間は約0.180mmです。M5ナットの外側配置と座金＋ナット計6mmは保持し、L字金具の外径15mm座金は変えません。外径10mmは今回のモデル上の指定で、手持ち部品の実測ではありません。

金具を含むねじ一式を先に取り付け、独立したレールフレームを後から組む順です。フレームの穴形状自体は加工せず、元の穴を使います。フレーム・ねじ先端・座金・ナット・スペーサーの納まりをCADで検査します。

浅い側の内側寄りの側板締結では、左右各1枚の外径15mm座金が通気孔の縁に約0.949mm重なります。ねじ頭は孔から約0.551mm離れ、座金の接触面積は孔だけを除いた基準面積の約96.57%です。これは接触形状の確認値で、荷重保証ではありません。

モジュール板2mm＋ノブ25mmを仮定した天板内面までの余裕は5.5mmです。すべてのモジュールに適合するという確認ではありません。

## 出力と印刷設定

review ZIPの`fastener-schedule.csv`・`fastener-schedule.json`には、位置別のねじ長さ、ナット高さ、内外の向きと数量をまとめています。実物仕様の確定や購入承認ではなく、今回のCADに表示した一式の表です。

R7印刷セットは15個のH2Dプロジェクトです。R5からメッシュを変更するのは`body-left`・`body-right`・`body-bottom-common`で、他の12プロジェクトはR5のバイト列をそのまま保持します。共通底板は同じものを2回印刷します。数量は本体6・蓋5・スタンド4・スペーサー8の計23個、保存オブジェクト22、プレート実行16回です。レール・アルミフレーム・金具・ねじ・座金・ナットは印刷数量に含めません。

H2D / 0.6mm / PLAのグローバル設定、オブジェクト設定、ノズル割当て、ブリム、保存済みの平置き姿勢を保持します。側板は外面を下にした既存姿勢、底板は既存の−45°平置き・左ノズルです。出力は未スライスの3MFです。組立座標のSTEP/STLと、印刷姿勢のSTLを区別してください。

## 再生成

リポジトリのルート、またはsource ZIPを展開したルートで実行します。Python3.12.14 / CadQuery2.7.0 / NumPy2.3.5 / SciPy1.17.0のR5専用環境を再利用します。

```sh
uv sync --locked --project engineering/tenbox-v2/r5
uv run --locked --project engineering/tenbox-v2/r5 python engineering/tenbox-v2/r7/build.py --out .cache/tenbox-v2-r7-build
```

出力先は存在しないディレクトリを指定します。`--publish-root .`は候補ファイルをこのチェックアウトの`public/`へコピーする指定です。サイトのデプロイや製造承認ではありません。

R7は保存済みR5 STEP/modelと元レールからの増分生成です。source ZIPには実際の入力と生成コードを含めます。`reference/user-feedback/`に初回と追加フィードバックの図示とハッシュ、`reference/rail-placement.json`にレールの固定commit・ハッシュ・配置を保存しています。元の著作権・ライセンス表示は保持します。

## 検証の範囲

生成先の`cad/geometry-checks.json`、`h2d/`のレポート、`project/tenbox-v2/r7-review.json`に結果を保存します。CADの有効性・全締結の向き・ねじの掛かり・干渉・穴位置、書き出した3MFのメッシュ・設定・配置、旧版のハッシュを検査します。R6の入力と出力もハッシュで不変を確認します。

公称CADの検査はBambu Studioでの実ロード・スライス、印刷、現物の嵌合・締付け・荷重・運搬の検証ではありません。薄ナットの使用とねじの長さを含め、この候補の実物条件は設計確認の対象です。
