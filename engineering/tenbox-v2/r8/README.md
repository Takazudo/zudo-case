# 10BOX-v2 R8 — アルミフレームの下側長穴へ固定位置を合わせる

前のセッションで未保存だったR8を、保存済みR7 `d5f74b664a875f4e0445c4c5c56a1af7818dcbb8`から再構築した設計確認候補です。追跡は[#143](https://github.com/Takazudo/zudo-case/issues/143)、確認用PRは[#144](https://github.com/Takazudo/zudo-case/pull/144)です。採用済みの指定はR5のまま、R5・R6・R7のソースと出力を保持します。製造承認は`false`です。

## 修正内容

ユーザーの旧10BOX側面図に合わせ、アルミ側面フレームの**下側の長穴**を、ケース側板のねじ穴へ合わせます。元データの`frameHoleIndex: 1`に対応します。

ケースの穴やねじを下げる変更ではありません。**ケース側板の穴、8mmスペーサー、ねじ・外側座金・ナットをR7の位置に固定**し、レール3本・アルミフレーム4枚・パダー4枚の一式だけを上げます。フレームの輪郭や長穴自体は変更しません。

| 寸法・配置 | R7 | R8 |
| --- | ---: | ---: |
| 使用するフレーム長穴 | 上側 | 下側（index 1） |
| ケース側固定軸のZ | 66.8205295mm | 66.8205295mm |
| レール面のZ | 75.5mm | 88.131103mm |
| レール面から使用長穴中心まで | 8.6794705mm | 21.3105735mm |
| フレーム一式のR7からの移動 | 0mm | +12.631103mm |
| フレームと側板内面の間隔 | 8mm | 8mm |

移動量12.631103mmは保存した元フレームの長穴中心間隔から求めた値です。表示上の推測や画像のピクセル寸法ではありません。8本のM5軸について、下側長穴の空間に軸の断面が完全に含まれることを確認します。

R7で追加した側面金具の両脇3mm、52か所の内側L字金具ナット、8か所の外側レール固定ナット、側板締結一式は維持します。金具やねじの寸法は従来の公称参照値であり、購入済みの金具を実測した値ではありません。

## 既存の蓋との関係

蓋は変更しません。天板内面はZ108mmなので、上げたレール面からの高さは次のとおりです。

- 使用可能な高さ: **108 − 88.131103 = 19.868897mm**。
- 以前の仮定「モジュール板2mm＋ノブ25mm」の合計27mmに対し、**7.131103mm不足**します。

19.868897mmはレール面から天板内面までの総高さです。27mmの仮定に対する残りの余裕ではありません。蓋の高さ変更や、すべてのモジュールが収まるという判断は、この修正に含めません。プレビューではR7/R8を同じカメラで切り替え、蓋との関係を確認できます。

## 再生成

リポジトリのルート、またはsource ZIPを展開したルートで実行します。Python 3.12.14 / CadQuery 2.7.0 / NumPy 2.3.5 / SciPy 1.17.0の既存R5専用環境を使います。

```sh
uv sync --locked --project engineering/tenbox-v2/r5
uv run --locked --project engineering/tenbox-v2/r5 python engineering/tenbox-v2/r8/build.py --out .cache/tenbox-v2-r8-build
```

出力先は存在しないディレクトリを指定します。`--publish-root .`は生成物をチェックアウト内の候補配信先へコピーする指定です。

source ZIPには再生成に必要な実入力を含めます。R7比較モデルはコミット済みreview ZIPの`model_data.json`を無変更でgzip圧縮し、元のSHA-256と出典を`reference/r7-model-receipt.json`に記録しています。R6/R7の過去の指示画像は元のリポジトリ位置に保持し、R8 ZIPへの重複収録を省きます。凍結R5ソース内のプレビュー等は過去の固定入力であり、今回のR8出力は生成先ルートの`tenbox-v2-r8.html`です。

## 検証と位置づけ

`project/tenbox-v2/r8-review.json`と生成先のレポートで、公称CAD、全8本の下側長穴通過、金具との干渉、保持した印刷形状と3MF、出典ハッシュを確認します。R8では上がったフレーム・パダーと蓋本体・蓋金具の検査も行います。

`review/verify_geometry.py`は別の検証経路で保存済みR7出力とR8出力を比較します。`preview/verify_browser.py`はR8そのものの表示とR7切替を検査します。実行した範囲と結果は各レポートに記録します。

ソフトウェアの検査はBambu Studioでの実ロードやスライス、現物の嵌合・締付け・荷重・運搬を確認したものではありません。既存の蓋の高さ不足を含めた設計確認候補です。
