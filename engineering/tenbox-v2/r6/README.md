# 10BOX-v2 R6 — ダブルレール・側板固定の確認候補

2026-11-23のユーザー図示に基づくR5からの改訂です。対象は独立した10BOX-v2系列だけです。**R6の設計確認待ち**で、R5の採用状態・保存済みソース・出力は保持します。追跡: [#143](https://github.com/Takazudo/zudo-case/issues/143)。製造承認は`false`です。

## 今回の変更

- 中央の単独レール2本を、7Uで使うnuts型ダブルレール1本へ変更。外周2本も対応するnuts型single v3を使います。zzmodの固定commitから取得した元STLを拡大縮小せず配置します。
- アルミ製3Uサイドフレーム自体の形状は保持し、2組をそれぞれ内側へ2.73407mm移動。固定穴・8mmスペーサーも同じ量だけ移します。外幅337.4mmと側面の8mm隙間を保持します。
- 底板の隅カットの上にあった、接触しない側板の受けを除去。直線の縁に受けを設け、金具とねじの位置を空けます。
- 側板にL字金具用の縦長穴を追加し、底板の既存スロットに合わせます。20×20×16mm、厚さ2mmの公称金具形状を組立表示に追加します。
- 浅い側の底板とアルミフレームの間に金具の足が干渉するため、共通底板に深さ1.5mmの金具座を4か所設けます。残る底厚は3.5mm。前後とも同じ底板を使い、前側だけ180°回転・Z+36mmに配置します。
- 金具の足に加えて実際のねじ頭も収めるため、レール一式を2mm上げ、モジュール面をZ74mmとします。底板のねじは低頭の頭を内側、ワッシャーとナットを底板の外側にします。厚さ1.4mmの頭の上に公称1.1mmの隙間を確保します。フレームの元の上側長穴を使い、通気孔16本／側は残します。

金具モデル、ねじ穴の遊びとCAD上の隙間は公称値です。金具の現物、締付け、荷重・運搬を確認したという意味ではありません。新しい底板の金具座に座る側面金具の足には、追加の底面ワッシャーを積みません。

底板の締結は**L字金具とねじを先に組み、後からレールフレームを取り付ける**順です。ねじ頭厚1.4mmと外側ワッシャー＋ナット計6mmは既存のユーザー確認値を使います。頭径12mm・M5×16の長さは干渉確認用の公称参照で、現物仕様の確定ではありません。従来の内側ワッシャー＋ナットの向きではフレームと干渉します。モジュール板2mm＋ノブ25mmを仮定した天板内面までの余裕は7mmです。

## 出力と印刷設定

R6印刷セットは15個のH2Dプロジェクトです。変更するのは`body-left`・`body-right`・`body-bottom-common`のメッシュで、他の12プロジェクトはR5のバイト列をそのまま保持します。共通底板は同じものを2回印刷します。数量は本体6・蓋5・スタンド4・スペーサー8の計23個、保存オブジェクト22、プレート実行16回のままです。レール・アルミフレーム・金具・ワッシャーはこの印刷数量に含みません。

H2D / 0.6mm / PLAのグローバル設定、オブジェクト設定、ノズル割当て、ブリム、平置き姿勢を保存します。側板は外面を下にした既存姿勢、底板は既存の−45°平置き・左ノズルです。出力は未スライスの3MFです。組立座標のSTEP/STLと、印刷姿勢のSTLを区別してください。

## 再生成

リポジトリのルート、またはsource ZIPを展開したルートで実行します。Python3.12.14 / CadQuery2.7.0 / NumPy2.3.5 / SciPy1.17.0の既存R5専用環境を使います。

```sh
uv sync --locked --project engineering/tenbox-v2/r5
uv run --locked --project engineering/tenbox-v2/r5 python engineering/tenbox-v2/r6/build.py --out .cache/tenbox-v2-r6-build
```

出力先は存在しないディレクトリを指定します。`--publish-root .`は候補ファイルをこのチェックアウトの`public/`へコピーする指定で、サイトのデプロイや製造承認ではありません。幾何のみの再生成は`build_geometry.py --out ...`、印刷プロジェクトは`build_print_projects.py --cad ... --out ...`を使います。

R6は保存済みR5 STEP/modelと元レールからの増分生成です。source ZIPはその入力と生成コードを含みます。元の著作権・ライセンス表示を保持します。`reference/user-feedback/`に今回の図示とハッシュ、`reference/rail-placement.json`に元レールの固定commit・ハッシュ・配置を記録しています。
