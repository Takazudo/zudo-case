## 実装した変更

- 下辺は底板を挟み込まないL字カバー。垂直単板向けU断面の上下反転は使いません。
- 上端は外側スカート・内側返し・屋根を、入れ子の矩形リングで作ります。２枚の立板が交わる角にも返しが侵入しません。
- `wall`は主要平坦部分の実肉厚です。横方向の嵌合/接着用すきまは肉厚とは独立し、外形と内側開口へ反映されます。
- **垂直な接着面だけ**に`fit_per_face + adhesive_per_face`の空きを設けます。屋根下面は金属上端、下辺の水平フランジ上面は底板下面へ直接当たるハードストップです。未定義のガスケットや上下の浮きは加えません。
- 蓋座面はその実ガード上端と一致。天板下面=座面+30mm、段差下面=座面-12mmを同じ関数から導出します。
- C1/C2を更新し、床＋壁の下辺C4、２立板の上端コーナーC5を追加。同じ本体断面/部品の切り出しです。

## 生成と検査

このフォルダーをリポジトリの`engineering/r9-fitfix-01/`に追加した状態で:

```sh
cd engineering/r9-fitfix-01
uv run --locked --project ../r9-prototype-01 python build.py
uv run --locked --project ../r9-prototype-01 python tests/test_geometry.py
uv run --locked --project ../r9-prototype-01 python tools/compare_r9_patterns.py
```

`build.py`は依存を追加しません。CadQuery/numpy/ezdxfだけを使用します。Python3.12/CadQuery2.7系の既存uv.lock環境での実行は**ローカル担当**です。このチャットの出力はPython3.13.5/CadQuery2.8.0で生成しています。

参照する`../r6-body`は現在のR9が引き継いだ公称配置の保存元です。必要な６入力をGit blob SHAで照合します。元ディレクトリへの書出しは無効化し、レール・PCB・金具の配置だけを再構築します。本体穴はR9のルール（36長穴＋10丸穴）で再作成します。**リポジトリ全体をcloneした環境でR9パイプラインを実行したものではありません。** `compare_r9_patterns.py`で現在R9の実DXFとの一致を追加確認してください。

既存出力を保全して比較する場合、`--out /path/to/new-empty-output`へ生成してください。一度に１ビルドだけ実行してください。`out/`は既定ではgitignore対象です。現物/ローカル確認後、現在のリポジトリ規約に合わせて候補出力の追跡方法を決めます。

## 材料・寸法の扱い

基本案は実肉厚1.2mm、比較案は1.0mm。主断面は屋根・外側壁・内側返しとも同じ厚さです。丸みを含む全域の自動最小肉厚検査や強度解析をしたものではありません。試験片の小さい浮出し文字は識別用で、構造壁とは別です。

基本案: ガード外形232.4×337.0mm、上端Z92.2、蓋座面Z92.2、天板下面Z122.2、天板228.2×332.8×1.5mm。底板下面Z0を基準とし、ガード全高93.4mmと上端座標を混同しません。

`fit=.15`＋`adhesive=.15`は片面の**空間配分候補**で、0.15mmテープを選定した意味ではありません。実際の空き0.30mmを埋めて保持できる接着剤、またはテープ/当て材の組合せが必要です。側面保持は未選定・未検証。上端の着座確認は乾式でもできます。ハードストップに接着層を追加する場合はその高さも再設計してください。

本体アルミ５枚、8mm離隔、レール寸法、単純載せ蓋＋外周バンドの方式は維持。C3の座金/工具/長穴範囲は今回の３件とは別の未確認事項です。厚い旧ガードやロック機構へ戻していません。

## 出力

`out/preview.html`は同じ生成形状を内蔵する単一HTML。WebGLが使えない場合はCanvas簡易描画に切り替わります。簡易描画の断面は三角形の選別で、CAD切断面ではありません。

- `pa12/t1p2` / `pa12/t1p0`: 各案の本体ガード６種類（16個）と蓋枠４個。
- `aluminum/body`: 本体３種類、必要枚数1/2/2。各案の蓋は`aluminum/t1p2`または`t1p0`。
- `coupons`: C1/C2/C4/C5。C2の壁・ガード・天板は比較間で再利用できます。
- `BOM.csv`: 個数、材料、参照パス。STLは１個の形状です。
- `validation.json`: 検証範囲と未検証事項。`environment.json`: 実行環境。
- `outputs-manifest.json`: 生成コード入力と出力のハッシュ。

1.2mm/1.0mmは**それぞれ専用の蓋**も生成します。比較する案を混ぜて注文しないでください。PA12とアルミは別の見積用ZIPです。
