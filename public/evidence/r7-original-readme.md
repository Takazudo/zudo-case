## 今回追加した構造

R6の３機種・レール位置・8mm側面スペーサー・ガード外形はそのままです。
蓋は **黒アルマイトのアルミ天板１枚＋黒PA12のL字枠４個**です。
天板の端は枠内へ入るため、アルミの切断端が外側に露出しません。
左右対称の２種類を各２個用意します。各L字枠に、前または後の隙間へ入る位置決め部とM3ナットチャンネルを一体化しました。

補助固定は前後各２本、計４本のM3。天板組立用の８本のM3は蓋を外すときに外しません。
PA12に直接タップを切らず、金属ナットを使います。前後固定ナットは上から縦チャンネルへ入れ、天板で抜け止めします。
ナットは蓋を正立させるとチャンネル底へ落ち、軸位置が揃います。蓋を傾けて外す際はナットがチャンネル内を動く場合があります。

**締付時の空きを埋めるため、本体内側に1.6mmのPA12圧縮スペーサーを４個追加しています。**
位置保持用の公称0.1mm接着層と合わせて、内面から差し込み部までの1.7mmを埋めます。
接着は脱落防止・位置保持だけです。締付時の圧縮荷重はスペーサーを通します。
この部品を省いて強く締めると、差し込み部やアルミ板が空き分だけ変形するため、省略しないでください。
接着層の実厚が違うときは、スペーサー側で調整してから締めます。

## ノブのための高さ

ケースの現在のレール位置のまま、平板を上端に直載せするとノブに当たります。
この版は **ケース上端ガードから天板下面まで30mm** の高さを作っています。
枠の下端とガードの間には、圧縮後0.5mmを想定したフォームテープを置きます。
本体ガード1.0mm版では、同じ蓋位置を保つため圧縮後0.7mmへ調整します。

高さ確認の仮定は、**レール最高面＋モジュールパネル厚2mm＋ノブ高さ25mm**。
中央にリブを横断させていません。パッチケーブルは抜いて閉じる条件です。
この25mmは実際に搭載するモジュールの仕様ではありません。実機のノブ・スイッチを測って確認してください。

| 3u60 | 328.6 × 152.2 × 1.5 | 332.8 × 156.4 | 69.479 | 1.299 |
| 7u40 | 227.6 × 332.2 × 1.5 | 231.8 × 336.4 | 78.438 | 1.223 |
| 7u60 | 328.6 × 332.2 × 1.5 | 332.8 × 336.4 | 89.891 | 1.223 |

PA12合計は枠４個＋本体側圧縮スペーサー４個の合計です。フォームテープ・接着層・金具は含みません。
閉じた状態の高さは、底の3mm脚から上面の模式ネジ頭まで128.8mmです。
幅・奥行は、既存の外側M5ナットや新設のM3頭の突出を含んでいません。

## 本体の加工変更

前板・後板に、M3用の **3.4×5.4mm縦長穴を各２個** 追加します。
既存のM5接合穴・レール取付穴は動かしていません。
既存M5穴はR6の丸穴のままです。ユーザー意図のブラケット誤差吸収のための長穴化は、寸法確定前の別項目です。

- R7の現行金属板は `manufacturing-r7/<機種>/aluminum/` にまとめています。
- 底、左右板はR6と同じ形状。前後板だけ新しいM3長穴を追加済みです。
- このフォルダの数量指定は、底１・前後２・左右２・天板１、合計６枚です。
- `engineering/<機種>/lid-r7/` に新しい蓋のSTEP、STL、DXF、穴配置・検証結果があります。
- 以前の `engineering/<機種>/...r6...` は比較のため残しています。前後板を発注する際に取り違えないでください。

## 組み立て順序

1. 実際に使う材料で `lid-stl/fit-coupon/` の試験片を造形し、M3ナットの収まりを確認する。
2. 各PA12枠の縦チャンネルへ前後固定用M3ナットを１個ずつ入れる。正立時に底へ落ちて穴が合うことを確認。
3. 天板用ナットを下面の六角ポケットへ入れる。４つの枠を揃え、天板を載せ、M3×6候補８本で仮締め。
4. 枠の接合隙間、天板との隙間を揃えて締める。天板が反るほど締めない。
5. 本体前後板に、追加スロットの位置を合わせて圧縮スペーサーを位置保持する。支持する積層厚を1.7mmに調整する。
6. 蓋の当たり材を貼り、モジュールや配線を挟まずに、前後の位置決め部を隙間へ入れる。
7. 前後各２本のM3を外側から挿入して補助固定する。軸が自然に通ることを確認し、無理に引き寄せて位置を合わせない。
8. 開けるときはその４本を外し、蓋ユニットをまっすぐ上に抜く。取り外したネジ・座金は紛失しないよう管理する。

## 検証した範囲

- 新設STLは単体１ソリッド、閉じたメッシュ、整合した面方向、正の体積を確認。
- CADとSTLの体積・外接寸法を確認。
- 蓋板と枠、本体パネルと枠、上端ガードと差し込み部の公称干渉を確認。
- レール／PCB／ブラケットは、保存済み実形状の保守的外接領域に対して新しい蓋の干渉を確認。
- 仮のノブ25mm領域を確認。実モジュールが入っているという意味ではありません。
- M3の模式形状とナット座／通し穴の関係を確認。
- 実機のたわみ、衝撃、振動による緩み、繰り返し寿命、成形公差、輸送時の荷重は未検証。

**蓋だけを取っ手にしてケースを持ち上げないでください。** 安全な持ち上げ荷重は未評価です。
防水・防塵・気密・積み重ね強度を主張する設計ではありません。

## 再生成

Python依存パッケージは `requirements-lids.txt` を参照。

```sh
python -m pip install -r requirements-lids.txt
python build_lids.py
python package_lids.py
```

蓋の寸法設定は `lid-parameters.json` です。
`source-data/r6-mesh-data.js` を元に蓋を追加するため、繰り返し実行しても蓋が重複しません。
本体の設計を変える場合は `build_geometry.py` を実行し、その生成結果を `source-data/r6-mesh-data.js` へ反映した上で、蓋を再生成してください。
古いブラウザー検証結果はR6の履歴です。R7の検証記録は `docs/r7-browser-validation.json` を参照。
