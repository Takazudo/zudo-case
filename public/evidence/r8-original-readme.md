# ZUDO CASE — R8 / Simple lid + travel bands

## この版

最終承認の構成を確認するプレビュー専用の版です。
**元の10BOXの「前後の段差を空きスペースへ下ろして位置決めする載せ蓋」＋「持ち運ぶときだけ別体のバンド2本」**を表示します。

- 蓋から本体への固定用M3、前後のロック穴、ナット受け、回転カム、スライダー、奥の固定フックを削除。
- 蓋は下ろす／真上に持ち上げる動作だけ。2mmずらす動作はありません。
- 天板をPA12枠へ組み立てるM3は残ります。このネジは開閉時に外しません。
- 元ケースの8mmスペーサー・前後約8mmの余白、蓋の30mm高さを維持。
- レール、PCB、基準となる本体寸法はR6/R7の表示用メッシュから引き継いでいます。
- バンドは既製品を別途用意する想定。表示は幅20mm・厚さ1.4mmの汎用的な模式形状です。特定の製品の再現ではありません。

## 開く

`zudo-simple-lid-preview.html` は単一HTMLです。ブラウザーで開きます。外部スクリプト・画像・フォント・ネットワーク要求はありません。
WebGL2 / DecompressionStream に対応したブラウザーが必要です。

ソース版はこのフォルダーを丸ごと展開し、`index.html` を開きます。

## 操作

- 「日常」：バンドなしの閉じた蓋。
- 「運搬」：閉じた状態でバンド2本を表示。
- 「使用中」：バンドを非表示にして、蓋を真上へ110mm取り外した表示。
- 持ち上げスライダー：0–150mm。
- 蓋を開く操作では、バンドを外した状態へ切り替わります。バンドそのものの解除・伸長のアニメーションはありません。
- 「蓋なし」：蓋を非表示。
- 透過・説明用色分け・前後の差し込みの模式断面・ノブの仮の確認領域。
- ドラッグで回転、スクロールで拡大、右ドラッグで移動。
- 部品をクリックすると名称を表示。
- PNGボタンで現在の全体表示を保存。

初期表示は7U / 40HP・日常の載せ蓋です。

## ケース寸法（mm）

| ケース | 本体アルミ W×D×H | 蓋の金属板 | 備考 |
|---|---|---|---|
| 3U 60HP | 330.4×154×91 | 328.6×152.2×1.5 | レール2本 |
| 7U 40HP | 229.4×334×91 | 227.6×332.2×1.5 | 3U+3U+1U、レール6本 |
| 7U 60HP | 330.4×334×91 | 328.6×332.2×1.5 | 3U+3U+1U、レール6本 |

本体ガードの見付け幅5mm・肉厚1.2mm、PCB厚1.6mm、側面スペーサー8mmは引き継いでいます。
蓋の金属下面はZ122.2mm。閉じた包絡高さは脚と天板ネジを含め128.8mm。バンド／外側のナット等の突起は別です。

### 前後の差し込み

見せ方だけを変更するのではなく、旧ロック付きの細い差し込み部を、単純な幅広の段差へ描き直しました。
PA12枠4個の前後側に半幅ずつ付く形で、中央には分割用0.4mmの継ぎ目があります。
厚さ2mm、上辺ガード上面から下へ12mm、ガード開口に対して公称片側0.7mmの隙間を仮定。
製造でのフィットを決定する値ではありません。実造形、板の反り、ガードの取付を含めて別途調整します。

## 保持とクリアランスの限界

- 蓋には機械的な抜け止めがありません。持ち運ぶときは外周バンドで保持する方針です。
- バンドで強く締め付けた際の蓋のたわみ、保持力、バンドの横滑り、バックルや他の部品との擦れは未検証。
- バンド幅・厚さは表示用の仮値です。商品選定や必要なバンド長さの確定データではありません。
- 蓋やバンドを持ち手として持ち上げることは想定していません。
- パッチケーブルを抜いて閉じる想定です。パネル2mm＋ノブ25mmを仮の包絡としています。
- 本体のブラケット穴位置、樹脂ガードの保持など、R6/R7からの未確定項目も残っています。
- 表示を軽くするため、一部の細かい締結部品とねじ山は省略されています。
- この版に製造用STL・STEP・DXFは含みません。既存の製造用ファイルは変更していません。
- 旧ロック案の製造データを、この載せ蓋の確定図として発注しないでください。

## 検証

`geometry-checks.json`：新しいPA12枠のBRep妥当性、前後ガードと差込部の公称すきま、レールユニットの包絡／金具上端からの距離。本体・レール全体の公差解析や応力解析を示すものではありません。
`browser-validation.json`：３機種×日常／運搬／蓋を外す状態、コントロール、幅390pxのレイアウトの確認結果。
テスト環境では管理設定によりfile://への移動が制限されるため、同じ単一HTMLをオフラインのChromiumコンテキストへset_contentで投入して確認します。ソフトウェアWebGL用にXvfbを使用。

## 再生成

HTMLだけをまとめ直す：

```sh
python build.py
```

段差などの表示用ジオメトリを再生成する（cadquery, numpyが必要）：

```sh
python prepare_models.py
python build.py
```

`reference-models.json.gz` は、以前の軽量比較版からの入力メッシュです。旧機構は入力の一部に含まれますが、再生成時に使うのは本体／天板／天板組立金具／当たり材だけです。古いロックは最終表示データへ入れません。
`model-data.js` は生成済みの現行表示データです。
`app.js` は描画、バンドの模式モデル、操作UIです。
Three.js等のライセンスは `THREE-LICENSE.txt` を参照してください。
