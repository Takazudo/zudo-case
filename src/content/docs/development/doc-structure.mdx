## 区分

正式なページは次の８区分のどれか１つが所有します。７つの現行区分は各系列の最新の状態だけを持ち、置き換わった旧版の読み物は`archive/`が所有します。現行版の指定は`project/current-selection.json`にあり、方針は[文書・表・資産の更新](./maintenance.mdx#現行とアーカイブ)にあります。

| 区分 | 内容 |
|---|---|
| 全体案内（`overview/`） | 系列の選び方、全体の状態、用語 |
| 金属ケース（`metal-case/`） | 3U60・7U40・7U60の単トレーの現行版（7U40はR11-BUILD-FEEDBACK-04、3U60・7U60はR6本体＋R8載せ蓋の基準）。状態、機種、設計、製作、検証、データ |
| 家庭印刷ケース（`printed-5mm/`） | 7U40・5mmの現行P6 |
| 10BOX-v2（`tenbox-v2/`） | 二段3U60HPの独立した家庭印刷ケース。最新版R8-LID-LEDGE-01 |
| 2WAY 実験設計（`two-way/`） | TW-01の作業版（A/B/C）とその入力であるF5原資料の参照 |
| 共通部品・元データ（`shared/`） | 複数の系列で使う部品と元データ |
| 開発・保守（`development/`） | サイトの起動、更新手順、この表 |
| アーカイブ（`archive/`） | 置き換わった旧版（金属7U40のR10以前、家庭印刷P5・P4・P3など）の記録。系列ごとに分ける |

## 旧URL

2026-11-06の再編前に公開していたURL（基準URL）は、すべて開ける状態で残しています。その後の移動で変わったURLは、同じ正式ページの別名（aliases）として残します。どちらの旧URLも検索・サイドバー・カテゴリ一覧に出ない互換ページになり、最終的な正式ページと旧見出しの移動先へ直接つながります。この表と互換ページは`project/doc-routes.json`から`node scripts/sync-doc-routes.mjs`で生成します。この表は文書の所有と移動の記録で、物理仕様の台帳ではありません。

扱いの意味: **維持**は同じURLのまま、**移動**は新しいURLへ移し旧URLを互換ページにしたもの、**移動・履歴**は以前の履歴区分へ移したもの、**アーカイブへ移動**は置き換わった旧版を`archive/`へ移したもの、**分割**は内容の一部を別ページへ移したもの、**新規**は再編で追加したページです。
