## 判断台帳

| ID | 採用したこと | 採用しない／変更したこと | 理由 |
|---|---|---|---|
| D01 | 平板５枚＋金具 | 厚いアクリルの凸凹接合 | 耐久性、保管配送、部品の単純化 |
| D02 | 黒アルマイトのアルミ | 鉄を最優先にする案 | 嗜好品の外観、アルミを望むユーザー指定 |
| D03 | 黒PA12専用ガード | 既製Lモールを露出して使う案 | 工作材・家具風の外観を避ける |
| D04 | 独立した実レールユニット | レールを外箱へ直付け、上面余白を塞ぐ | 元zudo-railの着脱性を維持 |
| D05 | 8mmスペーサー | 5mmを使い金具を避ける | 金具の厚さ・頭・ばらつきに余裕、上下２点固定を維持 |
| D06 | 厚1.2mm／被覆5mmを基本候補 | 厚3mm／被覆18mm | 用途は端の保護と意匠。体積・価格を削減 |
| D07 | 前後約8mmの余白 | 3Uの奥行171mmをそのまま維持 | レール前後に余裕がありすぎるという指摘 |
| D08 | ３機種、特に7U40を重視 | 3U60のみ | リュックで持ち運ぶ利用を重視 |
| D09 | 長穴による位置調整と締付 | 全穴の理想位置への依存 | 金具・素材のばらつきを吸収 |
| D10 | 単純な載せ蓋＋外周バンド | 毎回４本のM3、回転/スライドロック | 作業時間、複雑さ、破損懸念を減らす |
| D11 | 日常はロックなし、運搬時のみバンド | 常時の機械ロック | 日常の扱いやすさと持ち出し時の保持を分離 |
| D12 | レール費用を原価から除く | 一体の総原価へ混ぜる | レールは別途製作するユーザー指定 |

## 決まっていないこと

アルミ業者・最終材種の発注、長穴の全長/向き、ガードの保持、嵌合、バンド品番、天板の最終厚さやたわみ合否、ねじの購入仕様は未確定。外観方向の採用から、これらが自動で決まったことにしない。

## 再検討する場合

この台帳に理由と影響機種を残し、仕様・CAD・プレビュー・部品表・見積を同じ変更で追従させる。例えばロックを復活させるなら、R7を黙って「最新」に戻すのでなく、新しい判断として扱う。

根拠：会話抜粋U01–U11と、[版の履歴](./history.mdx)。
