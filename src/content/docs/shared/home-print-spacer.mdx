レールユニットのfixer外面とケース側板内面の間に入れる、家庭用3Dプリンター向けの中空円筒です。外側の1mm座金とは別部品です。版は**HOME-PRINT-SPACER-01**、状態は「家庭印刷での嵌合試作。現物の嵌合と締付は未確認」です。

## 寸法と数量

| 項目 | 値 | 扱い |
|---|---|---|
| 高さ | 8mm | 採用済みの離隔（[積層の設計](../metal-case/design/rail-stack.mdx)） |
| 外径 | 10mm | R6の仮寸法を引き継いだ試作値。現物測定値ではない |
| M5用貫通穴 | 5.5mm | 同上 |
| 数量（ケース１台） | 3U60: 4個、7U40: 10個、7U60: 10個 | 金属ケース３機種のレールユニット取付数 |

数量は金属ケース３機種の取付点の数です。家庭印刷ケースP5も内側8mmスペーサー10個を使いますが、印刷セットには含めておらず、このスペーサーを使うかどうかは記録されていません。2WAYの積層も同じ8mmですが、部品の指定はありません。

## ファイルと印刷

ファイルはリポジトリの`engineering/home-print-spacer-01/`にあり、公開のダウンロードは用意していません。

- 印刷ファイル: `frame-spacer-h8-od10-id5p5-mm.stl`（1個、単位mm。STLに単位情報はないので取り込み時にmmを指定）
- 生成: `python3 engineering/home-print-spacer-01/build.py`（Python標準ライブラリのみ）。OpenSCAD用の同寸法ソースは`spacer.scad`で、自動同期しない
- 記録: `manifest.json`にR6入力（`engineering/r6-body/design-parameters.json`）とSTL出力のSHA-256、寸法、個数、メッシュ検査結果

平らな環状面をベッドに置き、穴を垂直にして100%倍率で印刷します。サポートは不要です。まず1個を印刷し、実M5ねじが通ること、高さが8mmであること、fixerと側板の間で金具・ねじ頭と干渉しないことを確認してください。穴が縮む場合はスライサーの穴補正か`bore_diameter`を調整し、高さまで変わる全体拡大は避けます。

## 確認していないこと

材料・積層条件・締付トルクは未検証です。締付後の潰れや時間経過後の緩みは現物で確認します。メッシュ検査（閉じたメッシュ、面の向き、貫通穴、外形・体積）は形状の検査で、嵌合・締付強度・耐熱・運搬試験の合格ではありません。`engineering/release/`の承認済み製作データには含めません。
