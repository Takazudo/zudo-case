旧10BOX式ケースでは、縦長の通気孔をねじの調整穴として兼用したため、長期使用でねじが下へ移動したというユーザーの経験があります。これは別ケースの使用報告で、P5の耐久試験結果ではありません。P5は通気と締結を分離し、通気孔にねじを通しません。

| 項目 | P5の公称値 |
|---|---|
| 開口 | 幅3 × 高さ32mm、角R0.5mm、5mm壁を貫通 |
| 高さ | 中心Z46mm、下Z30／上Z62mm |
| ピッチ／隣接リブ | 11mm／8mm |
| 左右側板 | 各25個、中心U=−132…+132mm（11mm間隔） |
| 前後板 | 各16個、中心U=−82.5…+82.5mm（11mm間隔） |
| 合計 | 82個 |
| 幾何開口面積 | 左右各23.946cm²、前後各15.326cm²、計78.544cm² |
| 金具投影への最小距離 | 四壁とも4.000mm |
| 専用締結穴への最小距離 | 左右6.9394265mm、前後9.750mm |
| 外周への最小余白 | 25mm |

値はP5の保守ソースが生成する`VENTILATION.json`のものです。面積は丸めた幾何値で、ねじ穴と受け穴を含みません。流量、冷却能力、熱容量、防塵・防水等級を表しません。最小距離は生成した壁と、実アセンブリ金具の保守的な投影から再計算します。

専用締結穴は短い組立長穴28個とレール取付丸穴10個の計38個です。座金・パッド・ナット・ブラケットの受け面も残します。床・蓋の縁・蓋天板に通気孔はありません。

左右側板のJ3受け穴（各8個）は通気孔とも締結穴とも別の開口です。受け穴と金具投影の最小距離は約1.13137mmで、通気孔の4mm条件とは別に管理します。側板の輪郭・寸法と組立順は[P5の設計](./p5-design.mdx)を参照してください。

通気孔は[P5一式](./p5-print-files.mdx)の壁4枚に含まれ、[P5プレビュー](./p5-preview.mdx)で四壁とねじ周辺を確認できます。現物嵌合、実スライス、ASA反り・クリープ、機械強度、運搬、熱・防塵性能は未検証です。製造承認やサプライヤー発注ではありません。
