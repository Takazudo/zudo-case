旧10BOX式ケースでは、縦長の通気孔をねじの調整穴として兼用したため、長期使用でねじが下へ移動したというユーザーの経験があります。これは別ケースの使用報告で、P4の耐久試験結果ではありません。P4は通気と締結を分離し、通気孔にねじを通しません。

| 項目 | P4の公称値 |
|---|---|
| 開口 | 幅3 × 高さ32mm、角R0.5mm、5mm壁を貫通 |
| 高さ | 中心Z46mm、下Z30／上Z62mm |
| ピッチ／隣接リブ | 11mm／8mm |
| 左右 | 各25個、ローカルU=11k、k=−12…12 |
| 前後 | 各16個、ローカルU=11(k−7.5)、k=0…15 |
| 合計 | 82個 |
| 幾何開口面積 | 左右各23.946cm²、前後各15.326cm²、計78.544cm² |
| 金具投影への最小距離 | 四壁とも4.000mm |
| 専用締結穴への最小距離 | 左右6.9394265mm、前後9.750mm |
| 外周への最小余白 | 25mm |

面積は丸めた幾何値で、ねじ穴を含みません。流量、冷却能力、熱容量、防塵・防水等級を表しません。最小距離は維持ソースで生成した壁と、実アセンブリ金具の保守的な投影から再計算します。

既存の短い組立長穴28個、レール取付丸穴10個、計38個は形状・位置・向きを維持します。座金・パッド・ナット・ブラケットの受け面も残します。床・蓋の縁・蓋天板に通気孔はありません。

内寸226.4 × 331 × 89.5mm、外寸236.4 × 341 × 94.5mm、底板2分割と0.3mm継ぎ目、左右Y=−25/+25mmの支持、載せ蓋、元の204mmレール6本とPCBの配置はP3のままです。接合板や独立ガードは追加しません。構造12点と任意パッド／座金3形式を含む[P4一式](./p4-print-files.mdx)を使います。長壁は一体・45度平置き、床と屋根は分割のままです。

現物嵌合、実スライス、ASA反り・クリープ、機械強度、運搬、熱・防塵性能は未検証です。製造承認やサプライヤー発注ではありません。[P4プレビュー](./p4-preview.mdx)で四壁とねじ周辺を確認できます。
