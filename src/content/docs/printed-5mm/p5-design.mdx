P5-PRINTED-5MM-TAB-JOINTS-J3。製造承認・現物評価は未完了。

本体6枚をセットで交換する。P4の左右側板だけを交換して旧床・前後板と混ぜない。P4の蓋6枚と任意パッド／座金3型は再使用できる。

左右側板は上端・下端341mm、中段349mm、高さ98mm、厚さ5mm。下辺Z=-3.5。内壁X±113.2、Y±165.5、床Z0..5と屋根Z132.5..137.5は保持。内寸226.4×331×89.5mm。フタ外寸236.4×341mmは変更しない。

受け穴は左右各8個、タブは前後板8個＋床8個。前後板中心Z24/55、床中心Y±60/±100。片側穴余裕0.2mm、肩隙間0.15mm、先端引込0.3mm、実挿入4.7mm。公称値で現物適合は未検証。

一方の側板に前後板と底2枚のタブを横から入れ、反対の側板をX方向から合わせ、既存L金具を締結する。底を上から押し込まない。ケース組立後に元レールセットを取り付ける。位置決めはタブ、抜け止めは金具とネジ。圧入・スナップ・接着のみで固定しない。

構造12部品は各1個。任意パッドは横48、縦48、丸座金28。金属L金具は本体20＋蓋8。レール6、fixer2、padder6、内側8mmスペーサー10と関連金属部品は印刷セットに含めない。通気孔82、専用壁締結28長穴＋10丸穴を保持する。床2枚は180度同形、中央隙間0.3mm、±25mm対支持。床・屋根の中央接合板はない。

STLはmmで印刷姿勢、STEPは組立座標。長側板は一体、45度平置き済みで二重回転しない。ブリム0mm、単一ノズル325×320mm、最長辺350mm以下。右ノズル領域X25..350、Y0..320。側板実輪郭は約310.171349mm四方。H2D 3MFはユーザーのPLA・0.6mm設定を維持し、設計材料のASA想定と区別する。未スライスでG-codeはない。蓋の段差サポート、反り、嵌合、強度、クリープ、運搬は未確認。

フレーム離隔は左右8.00mm・前後約8.122772mm。空の通路を保証しない。受け穴と金具投影の最小距離は約1.13137mmであり、通気孔の4mm条件とは別。高さ5mm参考脚では底縁の公称接地余裕1.5mm。脚の潰れと机の凹凸は未確認。

uv sync --locked
uv run python build.py --out /tmp/p5-build
