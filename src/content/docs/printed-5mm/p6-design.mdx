P6-PRINTED-5MM-LID-SLOTSは、大きなフタ天板2枚と細長いL字の縁パーツとの接合位置を調整する版です。製造承認・現物評価は未完了です。

## フタ天板の長穴

天板は各225.8 × 165.05 × 5mm、2枚で1組です。各4か所、合計8か所の丸穴を長穴へ広げ、元の穴中心・板の外形・中央の分割・厚み・印刷姿勢を保持します。

| 項目 | 公称値・向き |
|---|---|
| 長穴の全長 × 幅 | 10.5 × 5.5mm |
| 穴中心からの調整量 | 長手方向へ±2.5mm |
| 左右の縁に近い穴 | X方向（左右の内外方向）へ長くする |
| 前後の縁に近い穴 | Y方向（前後の内外方向）へ長くする |
| 板の外周までの最小残り幅 | 公称5.45mm |

10BOX-v2と同じく、隣接する辺に対して直角方向へ逃がす考え方です。縁パーツを仮止めして位置を合わせ、座金とねじで締結します。長穴は締結位置の余裕であり、締結後に動かして使う機構ではありません。

## 本体と引き継ぐ部品

本体6枚、フタ縁4枚、任意パッド・座金3型はP5の保存済みデータと同じです。P5を印刷済みなら天板2枚だけを交換できます。

本体は左右側板の受け穴と、前後板・底板の一体タブで位置を決め、既存L金具とねじで固定します。左右側板は上端・下端341mm、中段349mm、高さ98mm、厚さ5mm。内寸226.4 × 331 × 89.5mm、フタ外寸236.4 × 341mmです。屋根下面Z132.5mm、上面Z137.5mmを保持します。

受け穴は左右各8個、タブは前後板8個と床8個です。穴の片側余裕0.2mm、肩の隙間0.15mm、先端の引込0.3mm、実挿入4.7mmは公称値です。現物適合は未検証です。

一方の側板に前後板と底2枚のタブを横から入れ、反対の側板をX方向から合わせ、L金具を締結します。底を上から押し込みません。ケース組立後に元のレールセットを取り付けます。タブは位置決め、金具とねじは抜け止めを担い、圧入・スナップ・接着だけで固定しません。

構造12部品は各1個です。任意の横パッド48個・縦パッド48個・丸座金28個、四壁の通気孔82個、壁の専用締結28長穴とレール取付10丸穴も変更しません。金属L金具は本体20個と蓋8個です。レール6本、fixer PCB2枚、padder PCB6枚、8mmスペーサー10個と金属部品は印刷品に含めません。

床2枚は180度同形、中央隙間0.3mm、±25mmの対支持です。床・屋根の中央接合板はありません。フレーム離隔は左右8.00mm・前後約8.122772mmですが、空の通路の保証ではありません。受け穴と金具投影の最小距離は約1.13137mmで、通気孔の4mm条件と区別します。高さ5mmの参考脚では底縁の公称接地余裕1.5mmです。脚の潰れ・机の凹凸は未確認です。

## 印刷姿勢と確認範囲

STLはmm単位の印刷姿勢、STEPは組立座標です。長側板は45度平置き済みで、追加の45度回転は不要です。長側板の輪郭は約310.171349mm四方、ブリム0mm、RightノズルのX25..350／Y0..320mm領域を使います。

H2D 3MFは保存済みPLA・0.6mm設定を保持します。ASAの材料想定とは別で、未スライスです。長穴を含む板の形状検査は、実スライス・現物嵌合・締結強度・反り・クリープ・運搬の試験を意味しません。

## 再生成

[P6ソースZIP](./p6-print-files.mdx)には、固定したP5天板のSTEP、穴中心・向き・寸法のパラメーター、長穴を切り出すソース、環境のlockを含めます。元のP5ファイルを上書きせず、2枚の交換形状を生成します。他13型は保存済みP5出力をそのまま使います。

```sh
uv sync --locked
uv run python build.py
uv run python regenerate.py
```

P6ソースZIPを展開したディレクトリで実行します。コマンドと検査の詳細は同梱READMEを参照してください。
