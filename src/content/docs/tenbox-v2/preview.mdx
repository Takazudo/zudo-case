## R7・今回の確認候補

2026-11-23の追加フィードバックに基づき、側面金具と受けの間隔、L字金具の内側ナット、側板側のねじ・座金・ナットを反映した確認候補です。中央のダブルレールも引き継ぎます。採用済みのR5とは別に保存し、R7の設計確認を待っています。

<PreviewLink path="/previews/tenbox-v2-r7.html">R7・金具間隔と内側ナットを開く</PreviewLink>

`Bracket clearance`で金具の両脇の間隔、`Inside nuts`で内側のナット、`Side screws`で側板の締結一式を確認できます。独立したレールフレームとケース側板の固定だけは、従来どおりナットが外側です。レール・金具・前後板・蓋を個別に隠し、回転・分解できます。金具と締結の寸法は公称CADで、現物の嵌合・強度・印刷を検証したものではありません。

## 採用済みR5の確認

<PreviewLink path="/previews/tenbox-v2-r5.html">保存済みR5の組立・H2D配置を開く</PreviewLink>

<PreviewFrame path="/previews/tenbox-v2-r5.html" title="10BOX-v2 R5・底板とH2D配置" />

以下は採用済みR5の画面です。R7の確認が完了するまで、R5のファイル・設定と現行版の指定を保持します。

| 画面 | 確認する箇所 |
|---|---|
| Assembly / Side / Back | 全体、本体6枚、蓋5枚、スタンドとフレーム |
| Insert / Front joint / Floor joint | 差し込み方向、14組のタブと受け |
| Rail gap | 元レール・PCBと側板の8mm隙間、フレーム固定 |
| Lid fit / Lid ledge / Lid top / Lid end | 1枚天板、縁と下棚の受け、継ぎ目 |
| Clipped floor | 四隅の12/16mmカット、残した4タブと9スロット |
| Case underside | 意図した三角の隅開口と底2枚 |
| Floor on H2D / Roof on H2D | 設定済み3MFと同じ床・天板の平置き姿勢 |
| Previous floor | R4の切欠き前形状との比較用 |

回転、zoom/pan、部品の選択・solo、分解、蓋持上げ、透過、表示色とカメラを操作できます。描画用メッシュは製造ソースの代わりではありません。[ダウンロード](./print-files.mdx)のSTEP/STLと設定済み3MFを使用してください。
