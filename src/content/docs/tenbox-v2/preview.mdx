## R8・現行版

**最新版R8のプレビュー**です。アルミ側フレームの下側長穴をケース側板の固定ねじに合わせ、中央ダブルレール、金具の両脇3mmの間隔、内側の金具ナット、側板の締結一式を表示します。

| 画面 | 確認する箇所 |
|---|---|
| Assembly | 本体・蓋・スタンドと、3本のレール・4枚のフレーム・4枚のパダー |
| Lower-slot detail | 元フレームの下側長穴と8本の固定ねじの位置 |
| Double rail | 中央1本のナット入りダブルレールと前後のレール |

| Inside nuts | 本体18個＋蓋8個のL字金具、両脚52か所の内側ナット |
| Side screws | 独立したレールフレームの固定、8mmスペーサーと外側の座金・ナット |
| Underside | 2枚の共通底板、底側のねじと意図した隅開口 |
| Lid fit | レール面から蓋の裏までの高さ19.868897mm |

回転、拡大、分解と、レール・金具・前後板・蓋の個別表示を操作できます。比較用の`R7 · Upper slots`を選ぶと、同じカメラ位置で下側長穴へ変更する前の配置を確認できます。現行の表示は`R8 · Lower slots`です。

## 蓋との高さ

レール面はZ88.131103mm、蓋の裏はZ108mmで、間の総高さは**19.868897mm**です。以前の仮定「パネル2mm＋ノブ25mm」の合計27mmに対しては7.131103mm不足します。入れるモジュールのパネルとノブの合計高さを、この寸法と照合してください。

表示と寸法は公称CADに基づきます。現物の嵌合・強度・印刷を検証したものではありません。印刷には[ダウンロード](./print-files.mdx)の設定済み3MFを使い、保存姿勢は[印刷配置と設定](./printing.mdx)で確認できます。
