## R8・統合済みの修正版

アルミ側フレームの下側長穴を、ケース側板の固定ねじ位置に合わせたR8です。ケースの固定位置を保ち、レール・フレーム・パダーだけを12.631103mm上げています。R7の中央ダブルレール、金具間隔、内側ナット、側板の締結一式を引き継ぎ、2026-11-23にリポジトリへ統合しました。印刷部品23点と設定済みH2Dプロジェクト15件はR7と同じです。

<PreviewLink path="/previews/tenbox-v2-r8.html">R8・下側長穴の固定とR7比較を開く</PreviewLink>

`Lower-slot detail`で下側長穴と固定ねじを確認し、`R7 · Upper slots`へ切り替えると同じカメラ位置で変更前と比較できます。`Bracket clearance`で金具の両脇の間隔、`Inside nuts`で内側のナット、`Side screws`で側板の締結一式を確認できます。独立したレールフレームとケース側板の固定だけは、従来どおりナットが外側です。

`Lid fit`では変更していない蓋との高さを確認できます。レール面から蓋の裏まで19.868897mmで、以前の仮定「パネル2mm＋ノブ25mm」には7.131103mm不足します。実際に入れるモジュールの高さ確認が必要です。

レール・金具・前後板・蓋を個別に隠し、回転・分解できます。寸法と干渉の確認は公称CADに基づき、現物の嵌合・強度・印刷を検証したものではありません。

## 採用済みR5の確認

<PreviewLink path="/previews/tenbox-v2-r5.html">保存済みR5の組立・H2D配置を開く</PreviewLink>

<PreviewFrame path="/previews/tenbox-v2-r5.html" title="10BOX-v2 R5・底板とH2D配置" />

以下は採用済みR5の画面です。R8のリポジトリへの統合後も、採用版の指定と以下の印刷・組立案内はR5を保持しています。

| 画面 | 確認する箇所 |
|---|---|
| Assembly / Side / Back | 全体、本体6枚、蓋5枚、スタンドとフレーム |
| Insert / Front joint / Floor joint | 差し込み方向、14組のタブと受け |
| Rail gap | 元レール・PCBと側板の8mm隙間、フレーム固定 |
| Lid fit / Lid ledge / Lid top / Lid end | 1枚天板、縁と下棚の受け、継ぎ目 |
| Clipped floor | 四隅の12/16mmカット、残した4タブと9スロット |
| Case underside | 意図した三角の隅開口と底2枚 |
| Floor on H2D / Roof on H2D | 設定済み3MFと同じ床・天板の平置き姿勢 |
| Previous floor | R4の切欠き前形状との比較用 |

回転、zoom/pan、部品の選択・solo、分解、蓋持上げ、透過、表示色とカメラを操作できます。描画用メッシュは製造ソースの代わりではありません。[ダウンロード](./print-files.mdx)のSTEP/STLと設定済み3MFを使用してください。

ローカル起動では同じチェックアウトの`public/`を、通常の本番ビルドでは専用プレビューホストを参照します。ソフトウェア表示の確認は現物の嵌合・強度検証ではありません。
