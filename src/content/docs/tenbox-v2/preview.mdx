## 確認する画面

| 画面 | 確認する箇所 |
|---|---|
| Assembly / Side / Back | 全体、本体6枚、蓋5枚、スタンドとフレーム |
| Insert / Front joint / Floor joint | 差し込み方向、14組のタブと受け |
| Rail gap | 元レール・PCBと側板の8mm隙間、フレーム固定 |
| Lid fit / Lid ledge / Lid top / Lid end | 1枚天板、縁と下棚の受け、継ぎ目 |
| Clipped floor | 四隅の12/16mmカット、残した4タブと9スロット |
| Case underside | 意図した三角の隅開口と底2枚 |
| Floor on H2D / Roof on H2D | 設定済み3MFと同じ床・天板の平置き姿勢 |
| Previous floor | R4の切欠き前形状との比較用 |

回転、zoom/pan、部品の選択・solo、分解、蓋持上げ、透過、表示色とカメラを操作できます。描画用メッシュは製造ソースの代わりではありません。[ダウンロード](./print-files.mdx)のSTEP/STLと設定済み3MFを使用してください。
