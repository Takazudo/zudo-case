現行R8の印刷セットに保存した**H2D・0.6mmノズル・PLA**設定を使います。全体設定・フィラメントとノズルの対応は変更していません。15個の3MFは、印刷形状とともにR7保存物をそのまま引き継いでいます。部品ごとのブリム／サポート設定も維持します。7U40家庭印刷のASAや一律ブリムなし設定をこの系列に流用しません。

## 底板と天板はLEFTノズル1本

| 項目 | 共通底板 | 天板 |
|---|---|---|
| 姿勢 | 広い面を下、yaw −45° | 広い面を下、水平 |
| 平面基準 | 主矩形中心X162.5/Y160mm | X4..321/Y10..300mm |
| 保存外形 | 316.850532×311.193678×5mm | 317×290×5mm |
| X範囲 | 4.074734..320.925266mm | 4..321mm |
| Y範囲 | 4.403161..315.596839mm | 10..300mm |
| Z範囲 | 0..5mm | 0..5mm |
| 選択ノズルと範囲 | LEFT、X0..325/Y0..320mm | LEFT、X0..325/Y0..320mm |
| 割当 | Manual、filament mapping `1 1`、object extruder `1` | 同左 |
| ブリム／サポート | なし／なし | なし／なし |
| 数量 | 1枚ずつ2回 | 1枚 |

2本のノズル範囲の和集合を使った「1本で入る」という判断はしません。底板の実際の投影凸包は、後方除外域から保守的に21.194489mm離れます。外接矩形だけはその除外域に重なるので、矩形の重なりだけで不適合としないでください。逆に輪郭検査の結果はスライサーのツールパス安全性を保証しません。

## Studioでの次の作業

[R8の印刷セット](./print-files.mdx)を展開し、`projects/`内の設定済み3MFをBambu Studioで開きます。底板と天板は左ノズル、その他も保存されたノズル割当て・配置・素材・プレート・ブリム・サポートを確認してスライスします。共通底板の`body-bottom-common.3mf`は2回、その他のプロジェクトは各1回印刷します。底板・天板の接着、反り、第一層とツールパスは実機で未確認です。他のプロジェクトの設定を一律変更しません。

保存したR8のレポートでは、3MFのXML・オブジェクト・部品・プレート参照と設定byteを検査し、R7と同じ印刷形状・配置であることを確認しています。底板と天板の単一ノズル範囲など、保存済み配置の根拠も保持しています。これはStudioアプリでロード・スライスした証拠でも、実印刷・嵌合・強度試験でもありません。[形状の根拠](./design-and-validation.mdx)も参照してください。
