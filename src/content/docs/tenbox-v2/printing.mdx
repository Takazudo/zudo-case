保存した**H2D・0.6mmノズル・PLA**設定を使います。全体設定・フィラメントとノズルの対応は変更していません。底板・天板以外の既存ブリム／サポート設定も維持します。P5のASAや一律ブリムなし設定をこの系列に流用しません。

## 底板と天板はLEFTノズル1本

| 項目 | 共通底板 | 天板 |
|---|---|---|
| 姿勢 | 広い面を下、yaw −45° | 広い面を下、水平 |
| 平面基準 | 主矩形中心X162.5/Y160mm | X4..321/Y10..300mm |
| 保存外形 | 316.850532×311.193678×5mm | 317×290×5mm |
| X範囲 | 4.074734..320.925266mm | 4..321mm |
| Y範囲 | 4.403161..315.596839mm | 10..300mm |
| Z範囲 | 0..5mm | 0..5mm |
| 選択ノズルと範囲 | LEFT、X0..325/Y0..320mm | LEFT、X0..325/Y0..320mm |
| 割当 | Manual、filament mapping `1 1`、object extruder `1` | 同左 |
| ブリム／サポート | なし／なし | なし／なし |
| 数量 | 1枚ずつ2回 | 1枚 |

2本のノズル範囲の和集合を使った「1本で入る」という判断はしません。底板の実際の投影凸包は、後方除外域から保守的に21.194489mm離れます。外接矩形だけはその除外域に重なるので、矩形の重なりだけで不適合としないでください。逆に輪郭検査の結果はスライサーのツールパス安全性を保証しません。

## Studioでの次の作業

[設定済み3MF](./print-files.mdx)を開き、左ノズル、保存配置、素材・プレート、各部品のブリムとサポートを確認してからスライスします。底板・天板の接着、反り、第一層とツールパスは実機で未確認です。他のプロジェクトの設定を一律変更しません。

3MFのXML・オブジェクト・部品・プレート参照と形状、設定byte、単一ノズル範囲をソフトウェアで検査します。これはStudioアプリでロード・スライスした証拠でも、実印刷・嵌合・強度試験でもありません。[形状の根拠](./design-and-validation.mdx)も参照してください。
