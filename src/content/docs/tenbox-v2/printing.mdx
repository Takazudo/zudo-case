現行R8-LID-LEDGE-01の印刷セットに保存した**H2D・0.6mmノズル・PLA**設定を使います。全体設定・フィラメントとノズルの対応は変更していません。15個の3MFのうち、蓋の前後縁の2個は中央棚を連結したメッシュに更新しています。残る13個はR8保存物とバイト単位で一致します。更新した2個も保存済みの印刷姿勢・オブジェクト設定・プレート設定を維持します。部品ごとのブリム／サポート設定も維持します。7U40家庭印刷のASAや一律ブリムなし設定をこの系列に流用しません。

## 底板と天板はLEFTノズル1本

| 項目 | 共通底板 | 天板 |
|---|---|---|
| 姿勢 | 広い面を下、yaw −45° | 広い面を下、水平 |
| 平面基準 | 主矩形中心X162.5/Y160mm | X4..321/Y10..300mm |
| 保存外形 | 316.850532×311.193678×5mm | 317×290×5mm |
| X範囲 | 4.074734..320.925266mm | 4..321mm |
| Y範囲 | 4.403161..315.596839mm | 10..300mm |
| Z範囲 | 0..5mm | 0..5mm |
| 選択ノズルと範囲 | LEFT、X0..325/Y0..320mm | LEFT、X0..325/Y0..320mm |
| 割当 | Manual、filament mapping `1 1`、object extruder `1` | 同左 |
| ブリム／サポート | なし／なし | なし／なし |
| 数量 | 1枚ずつ2回 | 1枚 |

2本のノズル範囲の和集合を使った「1本で入る」という判断はしません。底板の実際の投影凸包は、後方除外域から保守的に21.194489mm離れます。外接矩形だけはその除外域に重なるので、矩形の重なりだけで不適合としないでください。逆に輪郭検査の結果はスライサーのツールパス安全性を保証しません。

## 蓋の前後縁の印刷姿勢

中央棚を連結した前後縁は同一形状です。[単体ファイル](./print-files.mdx#蓋の前後縁だけを印刷する)を使う場合は同じSTLまたは3MFを2個分印刷します。一式の`projects/lid-front.3mf`と`projects/lid-back.3mf`を使う場合は各1回です。

保存姿勢は広い面を下にした対角45°配置で、Z=0..10mm、外接寸法は約265.801×265.801mmです。元の5mm外側ブリム・0.1mmブリム隙間とサポート設定を維持しています。追加した棚は既存の外形内に収まり、保存ノズル範囲と後方除外域に対するブリム込みの配置検査を通っています。

## Studioでの次の作業

[現行の印刷セット](./print-files.mdx)を展開し、`projects/`内の設定済み3MFをBambu Studioで開きます。底板と天板は左ノズル、その他も保存されたノズル割当て・配置・素材・プレート・ブリム・サポートを確認してスライスします。共通底板の`body-bottom-common.3mf`は2回、その他のプロジェクトは各1回印刷します。底板・天板の接着、反り、第一層とツールパスは実機で未確認です。他のプロジェクトの設定を一律変更しません。

現行版のレポートでは、3MFのXML・オブジェクト・部品・プレート参照、設定byteと配置を検査しています。蓋の前後縁だけを承認済みの連結形状へ差し替え、その他13プロジェクトの同一性を確認しています。底板と天板の単一ノズル範囲など、保存済み配置の根拠も保持しています。これはStudioアプリでロード・スライスした証拠でも、実印刷・嵌合・強度試験でもありません。[形状の根拠](./design-and-validation.mdx)も参照してください。
