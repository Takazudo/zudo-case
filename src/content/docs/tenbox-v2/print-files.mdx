## 蓋の前後縁だけを印刷する

前と後ろは同一形状で、組立時に180°回して使います。**共通ファイルを2個印刷**すれば前後がそろいます。

| ファイル | 使い方 |
|---|---|
| <PreviewLink path="/downloads/candidate/10box-v2-lid-frontback-connected-r01.stl">蓋の前後縁・共通STL</PreviewLink> | mm単位、Z=0の平置き・対角45°の保存姿勢。2個印刷 |
| <PreviewLink path="/downloads/candidate/10box-v2-lid-frontback-connected-r01.3mf">蓋の前後縁・H2D共通プロジェクト</PreviewLink> | H2D 0.6mm/PLA、1プレートに1個。同じプレートを2回印刷 |

中央2か所の不要な隙間をつないだ棚を持ちます。端のL字金具用開口、取付穴、下側の位置決め舌、外形寸法は維持しています。一式ZIPの`lid-front.3mf`と`lid-back.3mf`を各1回印刷する方法でも同じ前後2部品になります。共通ファイルを追加で2個印刷する必要はありません。

## ZIPを展開して開くファイル

設定済み3MFは印刷ZIP内の`projects/`にあります。Bambu Studioでプロジェクトとして開きます。

| ZIP内のパス | 印刷するもの |
|---|---|
| `projects/body-bottom-common.3mf` | 共通底板1枚。同じプロジェクトを2回印刷 |
| `projects/lid-top-single.3mf` | 天板1枚 |
| `projects/body-left.3mf`・`projects/body-right.3mf`・`projects/body-front.3mf`・`projects/body-back.3mf` | 本体の壁4枚、各1回 |
| `projects/lid-left.3mf`・`projects/lid-right.3mf`・`projects/lid-front.3mf`・`projects/lid-back.3mf` | 蓋の縁4枚、各1回。前後は中央棚を連結した現行形状 |
| `projects/stand-left.3mf`・`projects/stand-right.3mf`・`projects/stand-connector-front.3mf`・`projects/stand-connector-back.3mf` | スタンド4部品、各1回 |
| `projects/spacers-8.3mf` | スペーサー8個を1回で印刷 |

## 23個の印刷部品

| グループ | 数量 | 扱い |
|---|---:|---|
| 本体 | 6 | 左右・前後壁4＋同じ底板2 |
| 蓋 | 5 | 1枚天板＋縁4 |
| スタンド | 4 | 左右＋連結2 |
| 8mmスペーサー | 8 | 1プロジェクト・1プレートで8個 |
| **合計** | **23** | レール・PCB・金物を除く |

15プロジェクトには22オブジェクトを保存しています。共通底板を2回印刷するので、16回のプレート実行で23部品になります。「共通底板」を前後底板に加える3枚目として数えません。印刷ZIP内の`assembly-bom.csv`にも同じ数量を記録しています。

## 座標と入力の扱い

形状確認セットの通常STEP/STLは**組立座標**です。前底板のZ36..41mmは正常です。印刷は保存姿勢を持つ3MFを優先し、STLを使う場合は印刷セット内の`meshes/body-bottom-common-print.stl`・`meshes/body-left-print.stl`・`meshes/body-right-print.stl`が印刷姿勢です。

**現在使う版はR8-LID-LEDGE-01**です。現行指定は`project/tenbox-v2/current.json`、配布物のhashと検証記録は`project/tenbox-v2/r8-lid-ledge-01.json`を参照します。蓋の前後縁の2プロジェクトだけ形状を置き換え、その他13プロジェクトはR8保存物とバイト単位で一致します。旧R5〜R8のソース・ZIP・検証記録は再生成の根拠として保全しています。

[印刷設定](./printing.mdx)と[組立](./assembly.mdx)を確認してください。3MFは未スライスで、保存された記録では実印刷・現物評価は未実施です。
