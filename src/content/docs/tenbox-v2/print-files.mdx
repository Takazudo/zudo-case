## ZIPを展開して開くファイル

設定済み3MFは印刷ZIP内の`projects/`にあります。Bambu Studioでプロジェクトとして開きます。

| ZIP内のパス | 印刷するもの |
|---|---|
| `projects/body-bottom-common.3mf` | 共通底板1枚。同じプロジェクトを2回印刷 |
| `projects/lid-top-single.3mf` | 天板1枚 |
| `projects/body-left.3mf`・`projects/body-right.3mf`・`projects/body-front.3mf`・`projects/body-back.3mf` | 本体の壁4枚、各1回 |
| `projects/lid-left.3mf`・`projects/lid-right.3mf`・`projects/lid-front.3mf`・`projects/lid-back.3mf` | 蓋の縁4枚、各1回 |
| `projects/stand-left.3mf`・`projects/stand-right.3mf`・`projects/stand-connector-front.3mf`・`projects/stand-connector-back.3mf` | スタンド4部品、各1回 |
| `projects/spacers-8.3mf` | スペーサー8個を1回で印刷 |

## 23個の印刷部品

| グループ | 数量 | 扱い |
|---|---:|---|
| 本体 | 6 | 左右・前後壁4＋同じ底板2 |
| 蓋 | 5 | 1枚天板＋縁4 |
| スタンド | 4 | 左右＋連結2 |
| 8mmスペーサー | 8 | 1プロジェクト・1プレートで8個 |
| **合計** | **23** | レール・PCB・金物を除く |

15プロジェクトには22オブジェクトを保存しています。共通底板を2回印刷するので、16回のプレート実行で23部品になります。「共通底板」を前後底板に加える3枚目として数えません。印刷ZIP内の`assembly-bom.csv`にも同じ数量を記録しています。

## 座標と入力の扱い

形状確認セットの通常STEP/STLは**組立座標**です。前底板のZ36..41mmは正常です。印刷は保存姿勢を持つ3MFを優先し、STLを使う場合は印刷セット内の`meshes/body-bottom-common-print.stl`・`meshes/body-left-print.stl`・`meshes/body-right-print.stl`が印刷姿勢です。

保存済みZIP内のREADMEや生成記録には、現行指定を切り替える前の記述が残っています。配布物の内容と検証記録を保持しており、**現在使う版はR8**です。現行指定は`project/tenbox-v2/current.json`、配布物のhashと検証記録は`project/tenbox-v2/r8-review.json`を参照します。編集用ソース内の旧版入力も、R8の再生成に必要な保存データです。

[印刷設定](./printing.mdx)と[組立](./assembly.mdx)を確認してください。3MFは未スライスで、保存された記録では実印刷・現物評価は未実施です。
