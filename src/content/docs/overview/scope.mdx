## 製品側の要件

ユーザーが重視するのは**価格と最低限の安全性**、嗜好品としての外観、平板へ分解できる保管・配送の扱いやすさである。家具・工作材に見える既製L字モールをそのまま使う案は採用せず、黒PA12の専用部品で外観を揃える。

本体は金属板とL字ブラケットが構造を担い、樹脂は主に端の被覆・意匠を担う。ガードをバンパーや構造材として過大に作り込まない。蓋も可動部を減らし、運搬時の抜け止めは交換可能なバンドへ分離する。

## この計算に含めないもの

レール、fixer、padderなどのレールユニットの製作費は、ユーザーが別途用意しているためケース原価から除外する。ただしケースとレールユニットをつなぐスペーサー・座金・締結材はケース側BOMに含める。

モジュール、電源、バスボード、内部配線、ケーブル、認証、完成品の保証条件は今回のCAD一式で確定していない。金属ケース化に伴う内部の接触・絶縁も、最終実装時に検討項目として残す。ここで規格適合を主張しない。

## 根拠の区分

| 区分 | 例 | 文書での使い方 |
|---|---|---|
| ユーザー実測／確認 | PCB1.6mm、頭1.4mm、金具2mm、既存部品での収まり | 寸法根拠として引継ぐ |
| 元データ | pinned commitのレールSTL・KiCad | 外形・配置計算の根拠 |
| 保存済み計算 | R6の寸法、体積、検証JSON | その版の計算結果として扱う |
| 表示用仮定 | バンド20mm、ノブ25mm、ねじ頭径の模式値 | 実物確認が必要と明示 |
| 見積画面 | R3ガードの2,264円 | 対象版と数量を限定する |
| 過去回答の概算 | アルミ加工費、３機種原価の範囲 | 実見積ではない履歴として残す |

元資料と会話にない公差、締付トルク、強度、最新価格は埋めていない。原価の未確定項目はゼロでなく`null`として記録する。

整理時に行うのはMDXの構造、内部リンク、数量・足し算、コピーしたファイルのハッシュ等の点検であり、CADや実物の再検証ではない。[検証の範囲](../verification/release.mdx)に記録する。
