## 現在の計画

**黒アルマイトの平板アルミ５枚＋手持ちのL字ブラケット＋細い黒PA12ガード**でケースを作る。レールユニットは独立して取り外せる。蓋はアルミ板１枚とPA12枠からなる10BOX式の載せ蓋で、外へ持ち出すときだけ別体のバンド２本で保持する。

対象は3U・60HP、3U＋3U＋1U・40HP、3U＋3U＋1U・60HPの３機種。中心となるのは、リュックへ収めて持ち運ぶことを意図した**7U・40HP**である。

![R8・7U40の運搬イメージ](/assets/images/r8/7u40-travel.png)

:::warning[製作承認済みのデータはまだない]

採用仕様とCADの反映状態は一致していない。本体はR6の名目CAD、蓋はR8の表示モデルまで。**R8の製作用STL・STEP・DXF、ブラケット用の長穴、樹脂の嵌合・保持**を次に詰める。旧R7ロック蓋をそのまま注文しない。

:::
