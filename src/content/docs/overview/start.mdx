このリポジトリには、互いに独立した３つのケース系列と、系列をまたいで使う共通部品・元データがあります。まず読みたい系列を選んでください。各系列は自分の版と状態を持ち、ある系列の候補が他の系列の仕様を変えることはありません。

:::warning[製造承認済みのデータはありません]

どの系列にも製造承認済みファイルはありません（`engineering/release/`は空）。ソフトウェア上の生成・検査が通っていても、現物の嵌合・強度・運搬の確認とは別です。注文・支払い・製造承認はユーザーが別に判断します。

:::

## 金属ケース（3U60・7U40・7U60）

アルミ平板５枚＋L字ブラケットの本体と、真上へ外す載せ蓋＋運搬時の外周バンド２本を使う単トレーのケースです。7U40の現行候補R10-FULLSET-01はアルミ6枚・PA12 20個・家庭ASA 72個の１台分で、追加の有料試験片を前提にしません。

- 入口: [金属ケースの概要](../metal-case/index.mdx) ／ [状態](../metal-case/status.mdx)
- プレビュー: [R10一式の3Dプレビュー](../metal-case/resources/current-preview.mdx)
- ファイル: [R10一式のZIPと数量](../metal-case/design/r10-fullset-01.mdx) ／ [版別ファイル](../metal-case/resources/files.mdx)
- 次の作業: [金属ケースの次工程](../metal-case/next-steps.mdx)

## 家庭印刷ケース（7U40・5mm）

黒ASAの5mm板で本体と段付き載せ蓋を家庭印刷する別系列です。P5は本体6枚をJ3差し込み接合へ変え、P4の蓋6枚と任意パッド・座金を引き継ぎます。P4は四壁にUniform通気孔を持つ版、P3は通気孔のない最初の基準です。

- 入口: [家庭印刷ケースの概要](../printed-5mm/index.mdx)
- プレビュー: [P5の3Dプレビュー](../printed-5mm/p5-preview.mdx)
- ファイル: [P5のSTL/STEPとH2D 3MF](../printed-5mm/p5-print-files.mdx)
- 次の作業: [未確認の項目](../printed-5mm/index.mdx#次に確認すること) ／ 旧版は[P4・P3の履歴](../printed-5mm/history.mdx)

## 2WAY 実験設計（TW-01）

2つのモジュール入りトレーを対向させて運び、演奏時は分ける構成の寸法・姿勢を検討する作業版です。A／B／Cの構成を切り替えられます。閲覧・設定用の出力は製作CADではなく、単トレーの金属ケースや家庭印刷ケースの仕様も変えません。

- 入口: [2WAYの概要](../two-way/index.mdx)
- プレビュー: [TW-01 ワークベンチ](../two-way/preview.mdx)
- ファイル: [TW-01 ダウンロード](../two-way/resources.mdx)
- 次の作業: [検証記録と次の現物開発](../two-way/verification.mdx)

## この文書の位置づけ

会話・提供ファイル・リポジトリ内の生成記録を整理した設計／製作の引継ぎ資料です。最初の整理は2026-09-24（D1）で、以後の版はそれぞれのページに日付と根拠を記録しています。文書の整理だけで新しいCADを作ったり、荷重試験をしたり、業者へ注文したりはしていません。
