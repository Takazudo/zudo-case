## 用語

| 用語 | 本プロジェクトでの意味 |
|---|---|
| 3U・60HP / `3u60` | 60HPの１列。レール２本 |
| 7U・40HP / `7u40` | 40HPの3U＋3U＋1Uが同じ平面に並ぶ３列。レール６本 |
| 7U・60HP / `7u60` | 60HPの3U＋3U＋1Uが同じ平面に並ぶ３列 |
| fixer | レール端とケース側面を結ぶPCBパネル |
| padder | fixerの内側に重ね、平頭ネジの頭を逃がすPCBパネル |
| 内側スペーサー | fixer外面とケース内面の間を8mm離すナイロン部品 |
| 本体ガード | アルミ端と継ぎ目を覆う薄い黒PA12部品 |
| 蓋枠 | 天板を支え、ノブの高さを避け、前後の位置決め段差を持つPA12部品 |
| 長穴 | 締付前に位置を調整するための丸端スロット。ねじ山を切った穴ではない |
| `t1p2` / `t1p0` | 本体ガードの基本肉厚1.2mm／1.0mm |
| `qty` | ケース１台での注文数量。STLには部品１個のみが入る |

## 方向と寸法

寸法は原則**W×D×H、単位mm**。Wはレールの長手方向、Dは3U/1Uの列を並べる方向、Hは底から上への方向。CADの上方向はZ。

本体のアルミ外形、ガード込み外形、脚を含む高さ、蓋付き高さ、外側ナットやバンドの突出を区別する。リュックに入るかは、最大突出と保護材を含む現物包絡で確認する。

7Uはケースを上下に二段積んだ状態ではない。今回の新ケースでは**奥行が伸びる一つのトレー**として、底１枚と周囲４枚を使う。

「M5穴」と記載する場合も、通し穴・長穴・タップ穴を区別する。本体のR6出力はφ5.5の通し丸穴であり、採用意図の長穴はまだ作図していない。
