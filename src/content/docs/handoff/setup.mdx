## 現在のチェックアウト

このチェックアウトは公式`create-zudo-doc@5.27.0`で初期化済みで、生成されたフレームワーク設定、`package.json`、`pnpm-lock.yaml`を含む。確認に使った環境はNode.js 24.13.1、pnpm 10.30.3。Node.js 22以上を用意する。

新しいチェックアウトでは、リポジトリのルートから次を実行する。

```sh
pnpm install --frozen-lockfile
pnpm check:docs
pnpm check:assets
pnpm test:setup
pnpm build
pnpm dev
```

`pnpm install --frozen-lockfile`は追跡中のlockfileと依存定義が合わない場合に停止する。`pnpm dev`が表示するURLをブラウザーで開く。2026-09-24の`pnpm build`は成功し、44ページ、41文書ルートと検索項目、47公開資産を生成した。

## 文書のみのスナップショットを初期化する場合

`node scripts/setup.mjs`は、公式scaffoldをまだ取り込んでいない文書のみのスナップショットで使う一回限りの補助スクリプト。この初期化済みチェックアウトでは実行しない。公式scaffolderを一時フォルダーで実行し、MDX、設定、画像、設計資料を保護して土台を取り込む。衝突があれば上書きせず停止する。依存導入はscaffold取り込みの後に別途行う。

## バージョンを指定する

scaffolderの指定版は`5.27.0`。別版を試す場合は動作確認した版を明示する。

```sh
ZUDO_DOC_CLI_VERSION=確認したバージョン node scripts/setup.mjs
```

実際のコマンド・生成された依存情報は`.handoff/setup-record.json`へ記録する。npmへの接続が必要なのはローカルの初期化とインストール時。3D単体HTML自体は外部通信なしで開ける。

## 手動で初期化する場合

```sh
pnpm create zudo-doc zudo-case-doc-site --lang ja --no-i18n --no-git --no-install --yes
```

生成先のスターター記事を確認してから、このセットの`src/content/docs/`、`public/`、`zfb.config.ts`を移す。`engineering/`、`project/`、`AGENTS.md`は作業資料として同じリポジトリへ入れる。既存サイトへ混ぜる場合はセットアップスクリプトを使わず、記事と設定を意図的に統合する。

## 表示確認と公開前の注意

2026-09-24のChrome 146.0.7680.153でdesktop 1440×900、narrow 390×844を確認した。41文書ルートと8カテゴリが両幅で表示され、narrowでは横はみ出しがなかった。検索・テーマ・画像・R8/R6プレビューの操作も確認済み。経路別の結果、非空ダウンロード、画面記録はリポジトリの`project/browser-validation.md`にまとめる。ビルドやブラウザーの表示確認は、嵌合・強度・運搬などの現物試験を代替しない。

`noindex`は有効にしているが、アクセス制御ではない。`public/downloads/archive/`のソースZIPや見積画像を含め、**public以下は公開すると閲覧できる**。対外公開時は配布範囲を見直す。実装・構造の資料を勝手に秘密情報と断定してはいないが、どこまで公開するかは所有者が決める。

このセットはルートパス配信を想定。サブパス配信に変える場合は、iframeと画像/ダウンロードのURLも確認する。
