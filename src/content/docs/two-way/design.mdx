## 圧縮・位置決め・保持

両トレーは独立した金属平板のケースと固定レールです。低い演奏用リムを残し、背の高い位置決め部は取り外すカラーに持たせます。

| 要素 | 役割と限界 |
|---|---|
| カラーの座面 | 周辺部で圧縮を受ける設計仮説。座屈・局部変形は未測定 |
| 重なり・位置決め | 横ずれを抑える。名目の接触と実際の公差は別 |
| 捕捉ストラップ2本 | ガイドを通して座面の離脱を抑える。品番・縫製・張力・保持力は未確定 |
| エッジと金具保護 | 手・脚・トランク内張りへの引っ掛かりを抑える。現物確認が必要 |
| 緩衝材付きトランク | 両トレーを拘束して運ぶ目標。ケースの単独吊り下げ定格ではない |

パッキンはがたつき対策であり、横方向をそれだけで保持しません。バンド摩擦を唯一の荷重経路としません。

## 部品の行き先

| 部品 | 収納 | 演奏 |
|---|---|---|
| 本体・蓋トレー | カラーを間に対向させる | 本体は脚、蓋は別体45°スタンド |
| カラー | 基準は独立4枚、比較案は蝶番でつないだ2組 | 保護袋に入れて空のトランク |
| スタンド | トランク内の独立した袋と仕切り | 側板2枚＋横桟2本。接合・転倒安定性は未検証 |
| ストラップ | ガイドを通る外周2本 | 上側ガイドから抜き、丸めて空のトランク |

下面の必須ポケットはありません。スタンドやカラーをパッチ空間に収納しません。トランク表示で持ち上げたスタンド袋は分解表示であり、寸法予算では内側に計上します。

## 開梱の検討順

1. 電源を切り、安定した台に置く。
2. バックルを開き、上トレーのガイドからバンド端を抜く。
3. 浅いトレーを両手で支え、位置決め部から外して安全な場所に置く。
4. カラーを継ぎ目から横へ開く。ケーブルを支持材にしない。
5. スタンドを組み、浅いトレーを載せる。取り外した部品をトランクへ移す。

実ケーブル長・束の体積・回転時の干渉は未解決です。表示姿勢は静止配置で、連続した開閉機構ではありません。

## 採用しない機構

高い常設壁、外部リンク、大型共通スタンド、スライド壁・スリーブ、持ち上げカセット、必須の下面ポケット、モジュール入り蓋を支える蝶番、フライトケース定格の取っ手・ラッチ、閉じた一体カラーリングは復活させません。

購入蝶番の76 mm全長・15 mm幅・35 mm羽・15 mm穴ピッチはカラー部品をまとめるための入力です。76 mmをパッチ隙間や耐荷重に読み替えません。板厚・ピン・取付・段付きカラーの折り畳み干渉は[現物開発](./verification.mdx)で確認します。
