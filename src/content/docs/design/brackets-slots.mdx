## ユーザーが意図していること

手持ちの20×20×16mm金具には大きな差が見えなくても、材料・穴位置のずれでパネルが揃わなくなる危険を避けたい。**長穴で位置を調整し、矩形へ整えた後の締付で保持する**のが意図である。

「金具の穴をすべて正確に測らないと設計できない」という方針ではない。実測は必要な調整範囲と干渉を把握するために使い、量産部品の差は設計で吸収する。

![旧zudo-block底面パネルの長穴](/assets/evidence/original-zudo-block-bottom.svg)

このSVGはユーザーが提供した旧版の形状。物理単位が埋め込まれていないため、ここから新ケースの長穴寸法をそのまま確定しない。

## 確認済みと仮値

| 項目 | 値・状態 |
|---|---|
| 金具外形 | 20×20×16mm（ユーザー指定） |
| 板厚 | 実測2mm。微小な曲がりを考慮 |
| 占有厚の比較条件 | 2.2mmは設計側の仮定 |
| R6の金具穴中心 | 内面から10mmという仮値 |
| R6のアルミ穴 | φ5.5mmの丸穴 |
| R6の長穴 | 未実装。R9 7U40の5.5×7.5mmは試験候補 |

過去には幅5.5×全長7.5mmの短い長穴を候補として挙げたが、採用済み寸法ではない。旧SVGの長穴寸法に関する過去推定も、新図の承認値としては扱わない。

## 次の作図方針

基準となる位置を保ちつつ、調整したい方向に長穴を置く。全穴を無制限に動く形へするのではなく、板端を揃えて仮締めし、直角・対角を確認して本締めできる組立手順とセットで決める。

座金を使う場合は、長穴周囲の受け面と、内側への厚さ増加を確認する。丸穴をスロットへ変えてもねじ頭や金具の厚さは減らないので、8mm離隔の検討と分離する。

### 発注前の確認結果として残すこと

長穴の幅・全長・向き、基準穴、使用する座金の外径と厚さ、板端からの距離、仮締めで吸収できた実際のずれを記録する。許容トルクはまだ定めていない。

商品リンクは[ブラケットの商品ページ](https://www.alibaba.com/x/18paSt?ck=pdp)。現物の厚さ・形状はユーザーの実測を優先する。今回、商品ページの寸法図や価格を再取得してはいない。

## R9 7U40の試験候補

上記のR6説明に対し、R9では36個の金具接合穴だけを幅5.5×全長7.5mmの長穴へ変更した。中心から長手方向へ±1.0mm動かせる**試験候補**であり、サプライヤーの公差指定や現物合格値ではない。レール固定10穴は独立フレームの位置を保つ丸穴φ5.5とした。[R9断面](./r9-prototype-01.mdx)と`out/aluminum/hole-table.json`を参照する。

| 接合 | 長穴の長手方向 | 基準 |
|---|---|---|
| 底板と前・後板 | 前後方向、曲げ線と直交 | 底板下面と壁板外面 |
| 底板と左・右板 | 左右方向、曲げ線と直交 | 底板下面と壁板外面 |
| 壁板どうしの縦接合 | 各接合の曲げ線と直交する板面方向 | 壁板外面 |

曲げ線**沿い**のずれはこの長穴で吸収できない。金具穴ピッチと板穴ピッチをC3試験片と実組立で確認する。底板を基準に金具と壁板を仮締めし、外形・直角・対角を揃え、調整位置と座金の覆いを見て本締めする。締付順・トルク・緩み止めは実締結材を決めて記録する。

CADでは板端、穴間の肉、ガード接触、名目工具外形を確認した。一方、仮の外径10mm座金は壁側26長穴で必要な受け面を覆えない。外径11.5mm以上を候補に、実座金の内外径・厚み、頭径、工具アクセス、端部での受け面を確認する。
