## ユーザーが意図していること

手持ちの20×20×16mm金具には大きな差が見えなくても、材料・穴位置のずれでパネルが揃わなくなる危険を避けたい。**長穴で位置を調整し、矩形へ整えた後の締付で保持する**のが意図である。

「金具の穴をすべて正確に測らないと設計できない」という方針ではない。実測は必要な調整範囲と干渉を把握するために使い、量産部品の差は設計で吸収する。

![旧zudo-block底面パネルの長穴](/assets/evidence/original-zudo-block-bottom.svg)

このSVGはユーザーが提供した旧版の形状。物理単位が埋め込まれていないため、ここから新ケースの長穴寸法をそのまま確定しない。

## 確認済みと仮値

| 項目 | 値・状態 |
|---|---|
| 金具外形 | 20×20×16mm（ユーザー指定） |
| 板厚 | 実測2mm。微小な曲がりを考慮 |
| 占有厚の比較条件 | 2.2mmは設計側の仮定 |
| R6の金具穴中心 | 内面から10mmという仮値 |
| R6のアルミ穴 | φ5.5mmの丸穴 |
| 最終長穴 | **方向・全長・幅は未決定** |

過去には幅5.5×全長7.5mmの短い長穴を候補として挙げたが、採用済み寸法ではない。旧SVGの長穴寸法に関する過去推定も、新図の承認値としては扱わない。

## 次の作図方針

基準となる位置を保ちつつ、調整したい方向に長穴を置く。全穴を無制限に動く形へするのではなく、板端を揃えて仮締めし、直角・対角を確認して本締めできる組立手順とセットで決める。

座金を使う場合は、長穴周囲の受け面と、内側への厚さ増加を確認する。丸穴をスロットへ変えてもねじ頭や金具の厚さは減らないので、8mm離隔の検討と分離する。

### 発注前の確認結果として残すこと

長穴の幅・全長・向き、基準穴、使用する座金の外径と厚さ、板端からの距離、仮締めで吸収できた実際のずれを記録する。許容トルクはまだ定めていない。
