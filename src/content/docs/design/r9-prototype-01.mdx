## 再生成と判定の境界

R9のPython環境で`cd engineering/r9-prototype-01 && uv sync --locked && uv run python build.py`。プレビュー、断面、候補ZIPの再生成後、`out/outputs-manifest.json`のハッシュと`out/validation.json`を確認する。

現行の機械検査は`passed_with_flags`。外径10mmの仮座金は壁側26長穴で受け面条件を満たさない。外径11.5mm以上は検討候補で、部品選定ではない。蓋枠の一部干渉・引抜経路の名目検査を通しているが、全組立の干渉、実金具、接着保持、アルマイト後の嵌合、バンド荷重、天板たわみ、落下・疲労は未検証。[小片手順](../verification/fit-test.mdx)から確認する。
