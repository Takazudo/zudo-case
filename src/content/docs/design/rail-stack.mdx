## レールユニットを独立させる

レールの左右は、外側から`fixer → padder → rail → padder → fixer`。PCBは両方1.6mm。40HPレール長は元STLで204mm、60HPは305mmとしてR6へ記録されている。HPの公称値から再生成したり、60HPを比例縮小したりしていない。

| 要素 | 40HP | 60HP |
|---|---:|---:|
| レール長 | 204mm | 305mm |
| fixer＋padderを加えたユニット外幅 | 210.4mm | 311.4mm |
| 左右8mmスペーサー後のケース内幅 | 226.4mm | 327.4mm |
| 左右1.5mmアルミ後のケース外幅 | 229.4mm | 330.4mm |

計算式は`レール長＋2×(padder1.6＋fixer1.6＋スペーサー8＋アルミ1.5)`。

## ケースへの締付

内側から順に、**M5頭 → fixer1.6 → 内側スペーサー8 → アルミ1.5 → 外側座金1 → ロックナット**。padderは頭を収める層なので、頭下の締付長へは足さない。

頭下から外側座金までの公称積層は**12.1mm**。これはネジ長の購入指定ではない。ナットの掛かり・座金・実ねじ形状を加えて必要な長さを決める。

頭高さはユーザー実測1.3〜1.4mmから1.4mmを採用し、1.6mmのpadderに対して公称0.2mmの高さ余裕。以前の1mm仮定は使用しない。

## 8mmにした理由

fixerの外面と側板内面の間で、レール端の頭1.4mm、金具の占有厚2.2mm、金具固定の頭1.4mmが向かい合う想定では、`8−(1.4＋2.2＋1.4)=3.0mm`が残る。

5mmの場合は同じ仮定で残り0mm。元ケースで干渉を避けて固定点を下げていた経験を踏まえ、上下の２点支持を保てる8mm案を採用した。実際の衝突は頭の直径・位置にも依存するため、この足し算を全体干渉検証の代わりにしない。

## 7U側面

一枚の7U fixerに、各側3U padder２枚と1U padder１枚を取り付ける。ケースとの固定は各3U区画に２点、1U区画に１点、片側５点。3U単列は片側２点。

![7U fixerとpadderの配置](/images/r6/7u-layout.png)

7U fixerは約314.754456×60.015381mm。3U fixerより下へ約30mm深い。隣接する元データ間の微差を丸めず保持している。

元形状・コミットと計算記録：[R6の元データ](../resources/engineering.mdx)、[保存済み設計パラメータ](/evidence/r6-design-parameters.json)。
