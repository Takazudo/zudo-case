## 目的

高価な全周部品を発注する前に、**実際の黒PA12と1.5mmアルミ、使用する締結材**の組合せを確認する。試験片の新形状はまだ作っていない。このページは確認計画である。

| 試験片の対象 | 見ること | 次に反映する値 |
|---|---|---|
| 本体ガードの短いL断面 | きつさ、端の露出、外れ、アルミへの擦れ | 接触隙間、接着/保持、丸み |
| ガード継ぎ目と角 | 長さ誤差、角の浮き、他物へ当たる箇所 | 継ぎ目、分割位置、端面処理 |
| 蓋の前後差し込み | 2mm厚・12mm代・0.7mm隙間という仮条件が適切か | 差し込み厚/高さ/クリアランス |
| 天板の組立部 | ナットの収まり、締付で樹脂が潰れないか | ポケット寸法、ねじ長、当たり面 |
| 長穴と実ブラケット | 板端を揃えて締結できるか | 調整方向、長穴長、基準穴、座金 |

R7のナット嵌合試験片は、R7ロック用の形状。今回の載せ蓋の試験片としてそのまま使うことはしない。

## 注意する境界

「手で入った」だけでは運搬中に保持できることを証明しない。逆に、短い試験片のきつさを長い全周部品へそのまま適用すると、反りや角の誤差を見落とす。短片で値を絞った後は、１台分の組立で確認する。

この文書では合格に必要な抜去力、締付トルク、許容ガタを新たに設定していない。製品要件と試験手順を決めて、結果と一緒に保存する。
