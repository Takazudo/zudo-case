## 調達候補

これまでの第一候補は**JLCCNCの板金加工へ、材料＋外形＋穴＋バリ処理＋黒アルマイトをまとめて依頼する**方法。比較先としてタカチB2Fと国内板金会社、素材価格の基準として横山テクノの切板を挙げていました。

候補のサービスページは[調達先一覧](./bands-suppliers.mdx)にまとめました。新しい価格・納期・対応可能公差は取得していません。

## 同じ条件で見積もる項目

| 項目 | 現状の指定／確認事項 |
|---|---|
| 数量 | 試作１台、比較用10台／50台。各機種を分ける |
| 材質 | A5052が候補。A1100Pへの無断置換はしない |
| 厚さ | 1.5mm |
| 外形 | 機種別の底１、前後２、左右２。蓋は追加１ |
| 加工 | 直線外形、取付穴、長穴。曲げ加工なし |
| 穴 | M5は通し穴/長穴。タップ穴と区別 |
| 外観 | 黒アルマイト。黒PA12との組合せを現物確認 |
| 端面 | バリ取り。手が触れる端の仕上げ条件を合意 |
| 表面 | 許容傷、色差、吊り跡、切断面/穴内面の仕上がりを確認 |
| 吊り下げ | 7U40は専用の吊り穴なし。底・前・後は長穴だけで、黒アルマイト時の吊り下げ方法を確認する |
| 費用 | 材料、加工、表面処理、送料、税、検査、梱包を分ける |

長穴はユーザーが公差吸収を目的に要求しています。R6の丸穴DXFをそのまま最終図としません。

7U40（R11）では加工用の専用吊り穴（Ø4、6か所）を取り除き、機能穴だけを残しています。左右の板にはレール丸穴が各5か所、蓋には丸穴8か所があります。これらの穴や長穴が業者の吊り下げに使えるかは確認していません。業者は以前、「吊り下げに使える穴があれば追加の穴は不要」と回答していますが、これは個別の図面や長穴での吊り下げを承認したものではありません。

## 業者へ渡すパッケージの形

承認図の版番号、単位mm、板ごとの数量、部品名、STEP、DXF、説明PDF等を同じセットにします。STLは金属外形の唯一のマスターにしません。どの形式を業者が要求するかを確認します。7U40のアルミZIPでは、STEPとDXFは同じ板の別形式なので数量を二重に数えません。

3U60・7U60の`reference/*-r6-aluminum-NOT-RELEASED.zip`は、**寸法と形状の相談用**です。長穴・穴中心が未確定なので製作承認の指示は付けません。
