## ユーザーが意図していること

手持ちの20×20×16mm金具には大きな差が見えなくても、材料・穴位置のずれでパネルが揃わなくなる危険を避けたい。**長穴で位置を調整し、矩形へ整えた後の締付で保持する**のが意図です。

「金具の穴をすべて正確に測らないと設計できない」という方針ではありません。実測は必要な調整範囲と干渉を把握するために使い、量産部品の差は設計で吸収します。

このSVGはユーザーが提供した以前のzudo-blockの形状です。物理単位が埋め込まれていないため、ここから新ケースの長穴寸法をそのまま確定しません。

## 確認済みと仮値

| 項目 | 値・状態 |
|---|---|
| 金具外形 | 20×20×16mm（ユーザー指定） |
| 板厚 | 実測2mm。微小な曲がりを考慮 |
| 占有厚の比較条件 | 2.2mmは設計側の仮定 |
| 7U40の本体長穴（R11） | 40か所すべて15.5 × 5.5mm。公称CAD上の候補で、業者の公差指定や現物合格値ではない |
| 7U40のレール取付穴 | 丸穴10か所（独立したレール枠の位置を保つ） |
| 3U60・7U60の金具穴中心（R6） | 内面から10mmという仮値 |
| 3U60・7U60のアルミ穴（R6） | φ5.5mmの丸穴。長穴は未実装 |

## 次の作図方針

基準となる位置を保ちつつ、調整したい方向に長穴を置きます。全穴を無制限に動く形へするのではなく、板端を揃えて仮締めし、直角・対角を確認して本締めできる組立手順とセットで決めます。

座金を使う場合は、長穴周囲の受け面と、内側への厚さ増加を確認します。丸穴をスロットへ変えてもねじ頭や金具の厚さは減らないので、8mm離隔の検討と分離します。

3U60・7U60はR6の丸穴のままで、この方針による長穴化はまだ行っていません。7U40の結果を確認してから展開を決めます。

### 発注前の確認結果として残すこと

長穴の幅・全長・向き、基準穴、使用する座金の外径と厚さ、板端からの距離、仮締めで吸収できた実際のずれを記録します。許容トルクはまだ定めていません。

## 7U40の長穴（R11-BUILD-FEEDBACK-04）

7U40の本体長穴40か所は、すべて**15.5 × 5.5mm**です。以前の10.5mmの長穴を、片側だけ内側へ5mm延ばした形で、外側の端は変えていません。両側へ対称に広げたものではありません。

- 40か所すべての本体ねじ位置に内側の耳があります。ブラケットのある32か所は一体の座が内側の座金を置き換え、ブラケットのない上部8か所はOD15の内側座金を残します（[締結と座金](./r11-build-feedback-04.mdx#締結と座金)）。
- 本体と蓋のナットはケース内側、独立したレール枠とケースをつなぐナットはケース外側です。
- 長穴は板の調整用で、ブラケットの曲げ線**沿い**のずれまで吸収するとは限りません。金具穴ピッチと板穴ピッチは一式の実組立で確認します。

底板を基準に金具と壁板を仮締めし、外形・直角・対角を揃え、調整位置と座金の覆いを見て本締めします。締付順・トルク・緩み止めは実締結材を決めて記録します。7U40の組立の順番は[R11-BUILD-FEEDBACK-04](./r11-build-feedback-04.mdx#組立の順番)にあります。
