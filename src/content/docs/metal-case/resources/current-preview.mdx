## 操作する

どちらも元の単一HTMLをプレビュー用サイトで配信しています。埋め込み枠が狭い場合は別タブで確認します。左ドラッグで回転、右ドラッグで移動、ホイール（スクロール）で拡大します。

- R11：13のビューを切り替えられます。パネル・金具・元のレール類の表示を切り替えてすき間を確認できます。CADのメッシュと描画処理を埋め込んでいます。
- R8：約4.7MB。WebGL2とDecompressionStreamに対応するブラウザーが必要です。持ち上げスライダー、天板/外板の透過、差し込み部の色分け、断面の拡大、ノブ25mmの仮領域が使えます。

## 表示の意味

R11の分解表示の距離は説明用で、詳細ビューの断面は表示上の境界です。追加の製作上の継ぎ目ではありません。「蓋・四辺の内側ガイド」は蓋の枠8個を下から、「側面ガイドのはまり」は側面ガイドと本体上部の接合部の関係を示します。プレビューの描画確認はJSDOMとCPU canvasによるもので、実ブラウザーでの確認ではありません。

R8の「日常」はバンドなしの載せ蓋、「運搬」は外周バンド２本、「使用中」は蓋を真上へ外した状態です。バンドの解除や締付力のシミュレーションはなく、バックル、弾性、重なり、天板のたわみは模式化していません。クリックで部品名を確認できますが、その表示形状が発注用CADであるという意味ではありません。

:::warning[R8に発注データはない]

R8ソースの`manufacturingFilesUpdated`は`false`です。この版には製作用STL・STEP・DXFがありません。3U60・7U60の天板・位置決め部は製作形状への作り直しが必要です。

:::
